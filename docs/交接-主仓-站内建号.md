# 交接-主仓-站内建号

## 需求

站内手动创建账号（邀请制入口），只允许 LiZF 账号使用。2026-10-15 定稿，选项 A（顶栏按钮 + 弹窗）。

## 实现

### 后端（app.py）

- 常量 `ADMIN_CREATORS = {"LiZF"}`：站内建号白名单，将来加人改这一行。
- 新路由 `POST /api/admin/accounts`：
  - 非白名单账号 → 403 `{"ok": false, "error": "只有管理员可以建号"}`；
  - 未登录由 `before_request` 天然拦截 → 401；
  - 调用 `lykie_accounts.add_user()`（复用全部既有校验：用户名 2–24 字/字符集/防路径注入、密码≥4 位、查重、建目录、`ensure_user_files`）；
  - `ValueError` → 400 中文错误；
  - 成功 → `jsonify_user({"ok": true, "created": 新用户名})`。
  - **坑**：`jsonify_user` 会用当前登录者覆盖 `username` 字段（会话一致性机制），新账号名必须放 `created`，前端也读 `created`。

### 前端

- `templates/index.html`：
  - `#headerActions` 内「退出」左侧，`{% if username == 'LiZF' %}` 渲染「建号」按钮 `#adminAccBtn`；
  - `#adminAccModal` 弹窗（用户名/密码/确认密码 + 窗内错误行 `#adminAccErr`），**整个弹窗也包在 Jinja 条件里**，非 LiZF 账号的页面 DOM 完全无此弹窗；
  - `script.js` 版本 bump `v=m95 → v=m96`（style.css 未动不 bump）。
- `static/script.js`「管理员建号」段：
  - 开窗清表单 + 聚焦用户名框；关窗（取消/关闭/遮罩点击）清表单清错误；
  - 提交：前端校验非空 + 两次密码一致 → `api('POST /api/admin/accounts')`；
  - 失败：错误显示在窗内（不关窗）；成功：关窗 + `uiAlert('已创建账号：×')`；
  - 提交按钮防重复（disabled）；三个输入框 Enter 即提交；
  - 绑定全部 `if ($('xxx'))` 守卫，非 LiZF 页面静默跳过。

### 明确不做

- 账号列表/删号/改密（用户未点，将来真要管理可升级为独立页）；
- 弹窗 Esc 关闭（跟随现有弹窗惯例：遮罩点击 + 取消按钮，全站无 Esc 绑定先例）。

## 验收（已测，15 case 全过）

1. 未登录调 API → 401；非 LiZF 调 API → 403；
2. LiZF 页面有按钮+弹窗；DingRan 页面按钮、弹窗 DOM 均无；
3. 建号成功：users.json 新增哈希条目 + `data/users/<名>/` 三个空白数据文件，新号立即可登录、错密拒绝；
4. 重名 / 1 字用户名 / 含斜杠用户名 / 密码<4 位 → 400 中文错误，窗内显示；
5. 关窗后表单与错误残留清空；
6. 测试全程 monkeypatch accounts 路径到临时目录，真实 `data/` 零污染（已验证）。
