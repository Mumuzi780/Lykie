## 隐喻

不是精美日记本，而是**可视化大脑**：每录一次，同一词形的记忆深度 +1，义项/例句补全——对抗「感觉会、实际深浅参差」。词族其它词形挂在**旁系关系圈**，与自身义项分开。一次录入可挂上同一词的多词性释义。

## 录词

1. 输入原词  
2. **词性多选**：点几个词性 → 出几个义项框（框上标明对应词性）+ 选填释义/例句  
3. 可选来源 / 短语 / 旁系 → 保存  

页面三栏：**左档案 · 中录入 · 右详情**。

撞词（同规范化词形）：有释义/例句时 `record_count + 1`（整次提交只 +1），并按义项合并 sense；仅加旁系不加深。  
`record_count === 1` 不显示次数；`≥ 2` 显示「记过 N 次」。

API：`POST /api/assets/vocab` 支持 `senses: [{pos, meaning, examples}, …]`；亦兼容旧的单组 `pos/meaning/examples`。

## 自身属性 vs 旁系 vs 同句

| | 自身属性 | 旁系 | 同句 |
|--|--|--|--|
| 例子 | 同一词形 `abandon` 的 v. / n. | happy ↔ happiness | crucial ↔ realm（同一例句） |
| 存储 | `senses[]` | `related[]` | `co_sents[]` |
| 交互 | 多义项录入 | 录词旁系 chips | 详情例句旁「同句再录」→ 预填例句再照常保存 |

- 旁系词若不存在 → 建 `stub: true` 空壳词头（可点开补录）；`list_vocab` **默认排除** stub。  
- 正式再录该词（带内容，或无旁系的单纯录入）→ 转正。详情里「仅加旁系」不转正 stub、不加深。  
- 同句：不改加深逻辑；保存时带 `link_from` 双向挂边；删词清边。  
- 删词时清掉其它词指向它的 `related` / `co_sents` 边。

## 查阅

- 搜索一等公民；最近录入短列表（不含空壳）。  
- 详情：深度次数（若≥2）+ 多义项 + 例句 + **旁系 / 同句**（可跳转）。  
- 首屏主角是录词，不是词墙。
