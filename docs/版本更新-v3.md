> 面向用户与内测同学的版本说明。工程细节与按日摘要见 [`版本日志.md`](版本日志.md)；进题策略见 [`进题导入-设计草案.md`](进题导入-设计草案.md)。

## 一句话

**这一版把「自己的题怎么进站」做扎实了**：脏一点的文本也能扫题型、挑样板、预览确认再入库；Word 导入不再占一屏空白大框。

---

## 相对上一大版，你多了什么

### 导入（本版重点）

1. **五步流程**：输入 → 题型检测 → 按题型选样板 → 预览 → 入库。  
2. **题型总览**：只显示检出了哪些题型、各多少题、样板选了没有；点卡片再进该题型样板。  
3. **样板主路径**：从系统归并好的题池里点「用作样板」→ 确认 / 取消 / 微调。  
4. **兜底**：系统没切准 → 微调样板，或对照原文手选一道（不垫付站内识图；乱排版可复制页内洗稿提示词去站外 AI）。  
5. **可只导部分题型**：例如只选了选择题样板也能继续，会提示「只导入已选类型」。  
6. **判断 / 填空**可与选择进同一客观库；**简答**可同次另建 `原名·简答` 库（不与客观题混库）。  
7. **答案更稳**：标准写法是单独一行的「答案：C」或「参考答案：C」；说不清的答案在预览里手选，未确认不能入库。  
8. **Word**：选定文件后收起大粘贴框，只显示文件卡；要改字再「改用粘贴」。  
9. **主题**：导入页跟随答题页的浅色 / 深色。

### 上一大版已有、本版仍保留（便于对照）

- 文件夹整理题库、模考集合、结算相关界面。  
- 客观斩题、简答训练、Lykie 陪伴（聊天需服务端配置）。

---

## 使用建议（导入）

- 尽量保留「一、单选题」「二、填空题」等大题标题，分散各章的同型题才能归并。  
- 多数情况：题型页点进选择题 →「用第 1 题作样板」→ 确认即可。  
- 截图 / 排版很乱：先用页内「复制洗稿提示词」在豆包等免费 AI 整理，再贴回本站。  
- 本版擅长**带结构的文本题库**；不保证万能识别任意 App 截图垃圾。

## 本版明确不做（留到下一版及以后）

| 项 | 说明 |
|----|------|
| **分享题库 / 好友** | 朋友题库有交叉时，希望处理完能分享题目、不分享答题进度。完整好友系统偏大，**搁置到下一版**再定是「分享链接」还是「好友」。 |
| **版本更新提示** | 站内提示「有新版本」。当前用户很少，**下一版再做**。 |
| 站点垫付识图 / 公开注册 / 共享专业题库 | 产品定位不变，见 [`产品定位.md`](产品定位.md)。 |
