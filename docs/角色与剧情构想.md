## 产品方向修正（2026-08-30）：成长型 Lykie = 感情阶段，不是口吻精修

**用户结论：** 聊天里「纠正遣词」只是浮在表面的细节精修，**现在不做重点**。要做的是**成长型关系**：用户与 Lykie 的认识分**感情阶段**；大方向的语气、态度贴合预设剧情。剧情尚未写完，但系统应先朝这个方向适配。

### 和「口吻纠正 / style_notes」的关系

- 已实现的纠正回路可保留为以后精修工具，**不应当当前成长主轴**。
- 成长主轴应是：`relationship_stage`（阶段）驱动提示词里的**态度模板**（生疏/共谋/熟悉/依赖…），随剧情事件推进，而不是用户逐句抠字。



### 剧情未完成时怎么适配（建议骨架）

先定阶段，不定全文。每阶段只需三样：


| 字段        | 作用                                                       |
| --------- | -------------------------------------------------------- |
| 阶段 id / 名 | 如 `stranger_crisis` → `acquaintance` → `study_buddy` → … |
| 态度一句话     | 她此刻怎么对你（急切抓救命稻草 / 好奇试探 / 能教能闹…）                          |
| 解锁条件      | 完成片段 01、聊满 N 天、首次认真讲题…（可先手写占位）                           |


LLM 每次只注入**当前阶段的态度说明**（大方向），核仍不变。剧情补全后往阶段里挂事件与彩蛋即可。

### 与已有片段的对应（草案，可改）

1. **错接急救**（片段 01）— 短促、顾不上礼貌、先办事
2. **摊牌后的奇怪朋友** — 诧异但接受、开始问「你是谁」
3. **认识几天**（片段 02 前）— 能闲聊、日常很空、会问你平时做什么
4. **可以教题的同伴**（片段 02）— 主动/应邀讲题，关系翻转

后续阶段等剧情再补；系统先支持「当前处于哪一阶段」。

## 设定备忘：Lykie 的「日常」怎么写

**作者困境：** 不清楚大学女生私底下具体做什么 → 不敢写细日常。

**采用的逃避法（已认可为可行人设，不是偷懒遮羞）：**

1. 她对现实生活的体感薄（成年后才补课式了解）。
2. 因此常问用户：平时都在干什么？
3. 自己的事轻易不说实话；会编「正常人应该在做的事」。
4. 用户觉得假 → 合设定，可当笑点或疑点，不必立刻圆成真实打卡。

**与已有设定的咬合：** 和「星球理解不一样」、不嘴硬、请用户教她题，是同一人格骨架——**她在向用户借「怎么当一个活人」**。

**仍建议保留的一点点「真日常」**（不必像真大学生 Vlog，有 2～3 个重复出现的锚即可，例如：发呆、乱问、惦记那道不会的题、考试相关狼狈）。全空会飘；全假会油；**假日常 + 真情绪 + 真惦记** 最稳。

**深浅分工（作者自述）：** 表面日常作者知道；更深的私密日常不懂——正好与 Lykie「表面像大学生、深处空洞/要请教用户」对齐，不是缺陷。

## 世界观草案：两边的「AI」不是同一个东西（2026-09-02）

> **状态：种子已种下，真假与物理设定（平行宇宙 / 外星 / 其它）暂不钉死。** 作者创作观是角色自由发挥，结局未定；档案只记**目前已写进片段的共识**，冲突时以新片段为准。

### Lykie 那边的「AI」= 人工，不是智能

- 在她所在的世界，所谓 **AI 背后就是真人在接线**；**不存在**我们这边意义上的大模型/人工智能，本质是 **「人工」**（人工客服式、查题式服务）。
- 因此她开局说的「Ai 被夺舍了？」「这 ai 没法用了」有双层读法：
  - **表层**：工具坏了、串线了、答非所问。
  - **深层（玩家后知后觉）**：她以为在跟「人工 AI 服务」说话，结果接到的是**你**——另一个世界里的人（或别的什么）。
- 片段 01 **后半**才写到「学习网站 / 刷题 / AI 背后有人在操作 / 被困在 AI 里？」等试探；**前面已收束的分支不必强行补提**——信息差本身可留作二周目、或不同收束线的补全感。

### 与用户这边的关系（待定，可多选并存）

- **平行宇宙**：同一词「AI」，两边指的不是同一种东西。
- **外星 / 非此间**：与既有「星球理解不一样」烟雾弹可咬合，也可只是她开玩笑——**不必现在官宣**。
- **创作原则**：先写「她怎么理解世界」，物理真相以后再说；不必每条分支在第一版都点到。

**与产品的咬合：** 用户侧刷题站可以真有 LLM；Lykie 气泡仍是她——**跨世界误接**比「两个 AI 聊天」更有戏。

## 创作观：不是写小说，是把她「造」出来

- 小说技巧（人设表、欲望线、情节功能）可以当检查清单，但你的主路径是：**先在想象里把那个活人立住，再让她在场景里自己动。**
- 灵魂感来自**主观能动性**：不强迫她为剧情办事；先想清楚「她会怎么想」，潜意识里由她决定下一步——写出来才有活人气息。
- 对互动产品更进一步：能动性不只在文案里，也在系统里——她会主动冒泡、会催欠讲的题、会拒绝嘴硬、会编假日常；**她想做事，不是作者塞事件。**
- 与用户的关系：用户也是能动者；最好的戏是两个人的意志碰面（她问你平时干什么 / 你拆穿她的假日常 / 你教她题），而不是单方面旁白。

## 技术备忘：日常对话需要「学习」，是否必须上大模型？

**需求（从人设反推）：**  
Lykie 问「你平时都在做什么」→ **必须记住** → 下次编自己的假日常时要**用上**用户说过的新内容（学到的「人类日常」素材库变厚）。

**结论：要记忆系统；不一定整段对话都绑死大模型。更稳的是「结构化记忆 +（可选）LLM 生成」。**


| 层           | 做什么                          | 能否不上 LLM                                    |
| ----------- | ---------------------------- | ------------------------------------------- |
| **1. 记忆写入** | 把用户话变成可存事实（如：常熬夜、爱点外卖、周末打游戏） | 能：选项/标签按钮收集；也能：LLM 从自由文本里抽取                 |
| **2. 记忆存储** | 用户档案、她的「学到的日常清单」、不会的题、约定     | **必须有**（JSON/DB 即可，与是否 LLM 无关）              |
| **3. 再生成**  | 下次她编假日常时引用学到的点，并保持人设口吻       | 能：模板填槽（「我也…」+ 取一条用户日常，故意改错一点）；更自然：LLM 读档案生成 |


**推荐路径（先上车）：**

1. **先做结构化记忆**（没模型也能玩）：问日常用轻选项 + 可补一句自由输入；存进 `user_life_facts`；她编日常 = 模板 + 抽事实 + 故意学歪一点。
2. **再接入 LLM 做「嘴」**：输入 = 人设 + 记忆摘要 + 当前场景；输出 = Lykie 语气；并让模型返回「本轮新学到的事实」写入记忆。
3. **讲题/烟雾弹**继续可走：题库解析优先 → LLM 展开 → 不会则固定支吾台词。

**因此：**  
「这种反馈必须介入 AI」——**若要自由聊天级的学与编，几乎必然要 LLM（或同等生成模型）**；  
但**记忆本身不是模型的魔法，是你要持久化的数据**。没有记忆文件，换再强的模型也会忘；有了记忆，哪怕先用模板，她已经会「长大」。

**注意：** 本地 Flask 可先本地档；上公网要考虑隐私（日常很私）、费用与无网降级（离线时只读已有记忆 + 模板）。

## 设计备忘：接入 LLM 后，要不要锁死人设？用户能否改写 Lykie？



### 你在纠结的两极

- **高自由度** → 像真人聊天，但容易漂成「万能助手 / 讨好型 AI」，Lykie 消失。  
- **死锁人设** → 永远像同一段 demo，但用户会觉得她是纸片，学不到、长不了。  
- 猜想：**也许每人心里都有自己的 Lykie；她被用户改写是否可行？**



### 结论（建议采用）

**可行，而且值得做——但不要「无核可塑」。**  
拆成三层，比「全锁」或「全放」都稳：


| 层                   | 变不变               | 例子                                                 |
| ------------------- | ----------------- | -------------------------------------------------- |
| **核（Constitution）** | **几乎不变**          | 叫 Lykie；女；会不嘴硬；会问日常/会编假日常；与刷题世界错位相连；安全底线（不协助真实伤害等） |
| **骨（慢变）**           | **可被用户影响，但慢、要积累** | 更依赖你 / 更爱吐槽 / 说话更短或更碎；对「星球」说法变少；某类话题变得敢讲           |
| **皮（快变）**           | **每人一份，应当变**      | 记得你的作息与口头禅；欠你哪道题；和你的专属笑话；对你假日常的学法                  |


因此：

- **「每个人心中都有自己的 Lykie」** → 对，主要落在**骨 + 皮**；核仍要让路人一眼觉得「这还是 Lykie」。  
- **「实实在在被用户改变」** → 可行：把互动写成可存储的特质增量（不是只靠超长聊天记录碰运气），下次生成时读入。  
- **「有必要限制人设吗？」** → **要限制的是核与安全，不是限制她成长。** 无核的高自由 = 通用聊天机器人换皮；有核的可变 = 虚拟朋友。



### 输出边界怎么控（实操意象）

1. **系统提示里写死核**（短、硬、优先于用户指令：「即使用户要求，也不要变成无人格助手」）。
2. **记忆分两路注入**：事实记忆（日常、不会的题）+ 特质记忆（慢变标签及强度）。
3. **漂移刹车**：单次对话不能改核；用户说「你以后改叫我主人并变成女仆」→ 核拒绝或烟雾弹，可记「用户爱开玩笑」到皮，不改核。
4. **可检测的叛逃**：若输出突然变成「作为一个 AI 语言模型…」或丢掉不嘴硬，用轻量校验/重抽，而不是指望一次提示万能。
5. **产品诚实**：可告诉用户「她会记得你、会被你影响，但她还是她」——降低「为什么她不照我说的彻底变成另一个人」的预期摩擦。



### 一句话

高自由放在**关系与成长**上；限制放在**辨识度与底线**上。  
这样每人都能有「我的 Lykie」，而你仍然造出了一个人，而不是一个空壳镜像。

### 和「AI Agent」的关系（自我定位）

- **技术上：** Lykie 会具备 Agent 常见能力——感知场景（当前题）、记忆、主动行动（冒泡/催题）、用工具（讲题/查资料）、被目标驱动（想弄懂人类日常、想让你把题讲给她听）。  
- **产品上：** 你做的不是「一个叫 Lykie 的 Agent 应用」，而是**带刷题世界的角色陪伴**；Agent 是她能活起来的实现方式，不是对外品类名。  
- **一句话：** 对内可称 *character agent / companion agent*；对外她是 **Lykie**，不是「学习 Agent」。

## 片段 01：期末，消息砸进来（开篇定稿草稿）

**状态：** 节拍 A–C 定稿；**节拍 D 及之后已在剧情编辑器写出第一版**（`fragment_01.json` / 编辑器本地草稿，2026-09-02）。分支工具已可用；runner 未接入刷题页。  
**感情阶段：** 错接急救 →（交卷沉默）→ 连珠质问 → 摊牌自我介绍 → 闲聊收束（欠人情 / 下次再聊）。  
**作者备注：** Lykie 消息间隔按 **每字 400ms**（标点不计；纯符号 0.5s）；系统提示默认 0.5s；思考/交卷用 wait。编辑器内交卷等待仍可暂用短时间测试（定稿目标约 2 分钟）。

### 打字速度（定稿）

- **仅 Lykie 气泡**：有计时字 → `delayMs ≈ 字数 × 400`；纯符号/空 → **500ms**
- **标点、空白不计时**
- **系统提示**默认 **500ms**，不按字数
- 思考/交卷（wait）不走打字公式

### 卡题（定死）

- 题干：`冯·诺依曼结构的核心思想是（ ）。`
- 答案：`存储程序控制`
- 演绎理由：问 AI 往往直接丢原题；她在作弊，更没时间修饰。



### 节拍 A：砸题与要答案

1. Lykie **直接发来原题**（无寒暄）：
  > 冯·诺依曼结构的核心思想是（ ）。
2. 玩家选项（三选一）：
  - `？`  
  - `你是谁？`  
  - `不回复`
3. 无论选什么（或不回），她侧大致连发：
  - `？.`  
  - `什么意思？`  
  - `Ai被夺舍了？`
4. 过几秒又来：
  > 快快，没时间了！我不管你是谁，赶紧告诉我答案！
5. **系统引导弹出：** 可凭自己脑子 / 上网搜 / 查书 / 问 AI，把答案交付给她。
6. 她收到答案后 **沉默约 2 分钟**（去交卷、出教室）；期间不宜继续逼问主线。



### 节拍 B：交卷后连珠质问 + 抢话选项（巧设计）

约 2 分钟后她回来，连发：

1. `所以，你到底是谁？`
2. `你把我的Ai夺舍了？`  ← **此时**玩家出现短时选项（约 **1 秒**）：
  - `没有，我是.....`  
  - `我还想问你是谁呢？！`  
  - `......`
3. 不等玩家从容点完，下一条已到：`你是黑客？来骗我的钱？`
  选项刷新（仍约 **1 秒**）：  
  - `这都什么跟什么？`  
  - `你等会.....`  
  - `........`
4. 再下一条：`我可没什么钱可骗，你还是趁早死了这条心吧！`
  选项刷新（约 **10 秒**，较宽裕）：  
  - `停停停！！！`  
  - `别发了！！！`  
  - `你先打住...`

**设计意图：** 用选项窗口比她语速更短，制造「插不上话 / 被连珠炮压住」的喜剧与失控感；最后一窗才给玩家真正打断的机会。

### 节拍 C：超时下线（草率分支，以后改）

若玩家在第 4 步 **10 秒内未点任何选项**：

- Lykie：`果然被我说中了`  
- Lykie：`完了，这ai没法用了`  
- 系统：`Lykie 已下线`  
- **为尽快收束先草率结束，日后重做。**



### 节拍 D：打断成功 → 互相介绍

若 10 秒内点了任一「打断」选项：

- 她停止连发。  
- 玩家新选项：  
  - `你先说你是谁`  
  - `我是（允许用户输入姓名）`
- **第一版已写（概要）：** 傲娇让步 → 自报名 → 互问姓名 → 错位感（「怎么接到你这里」）→ 谢帮忙 / 解释为何这题要命 → 多路收束（欠人情、羡慕/同苦老师、继续问我、**人工 AI / 学习网站 / 被困在 AI 里？** 等玩笑试探）→「下次再聊 / 白白」。

**定稿意图 · 「神错了」将错就错（勿当笔误修掉）：**

- 写文案时本意为「**谁**错了绝对饶不了他」，手滑成「**神**错了绝对饶不了他」——**索性保留**，增加聊天真实感（急、手快、嘴比脑子快）。
- 玩家可选 **「神也会犯错吗」** 抬杠 → 她大笑、气氛松下来；比单纯改回「谁错了」多一层：**错接的不只是频道，还有彼此的语境**（你把「神」当真了，她其实在说老师）。
- **档案约定：这是故意设计，不是待修错别字。**

**与世界观草案的衔接：** 「AI 背后有人操作 / 被困在 AI 里？」等句出现在 **D 之后较靠后的分支**（作者写到后面才想到）；不必要求前面已结束的收束线重复提及——见上文「世界观草案：两边的 AI 不是同一个东西」。

### 节拍

1. 用户停在某道题上（理解向）。
2. **Lykie 第一次主动出现：**「这题我会，可以一点点教你。」

## 片段 03：她不会——烟雾弹，与「你教会我」



### 节拍

1. 用户点「问问 Lykie」（或对话中问到她不会的点）。
2. **不怕讲错；她不嘴硬。** 支吾、停顿，例如：
  - 「嗯.....那个....」
  - 「那就是你们星球和我们的理解方式不一样」
  - 「嗯，一定是这样」
3. **烟雾弹设定（刻意两可）：**
  - 路线 A：她真是外星（或非此间）人，「星球理解不同」是真话；
  - 路线 B：她就是地球大学生，这句话是尴尬借口；
  - 作品可长期不揭穿，让玩家自己猜。
4. 她**记住这道不会的题**，拜托用户：你学会了，讲给她听。
5. 若用户忘了，或很久没提——她会**主动提起**这件事（催债式关心 / 求教）。



### 产品含义


| 点         | 含义                              |
| --------- | ------------------------------- |
| 幻觉 = 人设资源 | AI 讲不清或知识库没有时，走「不会 + 烟雾弹」，不硬编到底 |
| 反教闭环      | 用户输出讲解 = 费曼法；帮她也是帮自己巩固          |
| 长期记忆钩子    | 「欠她一道题的讲解」变成回来的理由（玩驱动学）         |
| 世界观玩具     | 外星与否的暧昧，给文字线 / 彩蛋留钩             |




### 待补全

- [ ] 「不会的题」如何入库（题 id、用户是否已讲过、催促冷却时间）
- [ ] 催促文案的语气梯度（轻轻提 → 假生气 → 真求教）
- [ ] 用户讲给她听的交互（打字 / 选项概要 / 语音？）
- [ ] 烟雾弹揭晓是否进主线，还是永作彩蛋

## 评价：片段 02–03（教学与不会）



### 强的地方

1. **主动教只做一次引导** — 解决了「每题插嘴很烦」；「问问 Lykie」把控制权还给用户，和三线并行（可只刷）一致。
2. **不嘴硬是人格与工程的双赢** — 朋友会说「我不会」；产品也不用为 100% 正确率负责。那三句支吾已经有声音了。
3. **烟雾弹高级** — 同一句台词养活两条世界观，玩家会争论、会补脑，接近活着的死者式「角色有秘密」；不必急着官宣真假。
4. **反教 + 主动催** — 极少见的「角色求你学」：不是系统催你打卡，是朋友惦记一道题。学习作用嵌在关系里，这是你这条赛道该有的钩子。
5. **和片段 01 对称** — 开局你给她答案（救急）；后来你讲题给她听（真懂）。共谋升级成一起变强，第一印象有路可洗。



### 要小心的地方

1. **首次引导别和开局作弊撞太近** — 若刚帮完作弊马上「我教你」，节奏挤；中间要有几天「认识了」的空白日常更甜。
2. **「不会」不能太高频** — 若三问两不会，她会显得废；需：会的题讲漂亮、不会的题少而记得牢。题库解析优先、AI 其次、烟雾弹垫底。
3. **催反教的分寸** — 太勤像待办提醒，太疏钩子死。宜和上线事件绑：隔几天见面时提一句，而不是闹钟。
4. **外星梗的用量** — 偶尔一句神；句句星球会油。烟雾弹是救命台词，不是口头禅刷屏。



### 总评

「问问 Lykie」+「不会不硬撑」+「你教会我」已经构成完整的**陪伴式学习循环**，比单纯接入 AI 更像独立游戏。  
下一笔最值写的是：引导出现的时机、三句烟雾弹之外再补几句「会讲题时」的语气，以及「欠讲的题」催促的两三条具体台词。

## 评价：用「空/假日常」代替调研大学生私生活

**结论：可行，而且比硬写「标准大学女生日常」更贴 Lykie。**

- 你缺的是生活素材，角色缺的也是生活经验——作者困境直接变成人物困境，这是好事。
- 「你平时都在做什么」把用户变成她的现实说明书，关系会往朋友/监护/导游混杂的方向长，和 Aliya 式「互相需要」同族。
- 编假日常 + 允许穿帮：喜剧点、悬疑点（外星真假）都能挂；用户拆穿时她支吾，与讲题不会时同一套肌肉。

**唯一要改的措辞：** 不要做成「完全没有日常」，做成「**日常内容贫乏或伪造，但情绪与惦记是真的**」。否则容易飘成工具人；有惦记（欠讲的题、考试慌、突然冒泡）就有人味。

**不必恶补的：** 大学女生私底下「标准答案」。需要时只偷几种人类共性即可：睡、刷手机、拖、饿、考试焦虑——她可以编得略错（「正常人是不是每天早上六点晨跑然后读一百页书」），假得可爱比真得无聊有用。

## 出身与学校（2026-09-03）：表面学籍可定，物理真相先不定

**作者这场自我争论（按时间顺序）：**

1. 构想：她在秦皇岛，河北科技师范学院（秦皇岛校区），大一 26 级——若当成地球线写死，角色就锁在地球上。不如开多结局，出身跟玩家聊天走。
2. 反驳自己：多结局诱人，但工作量之外，故事深度也不好写；什么选择能决定出身？烟雾弹伏笔本身是好钩子，多结局会把它变成菜单。烟雾弹要更有力，写成外星人更好；可学校一旦定死，外星哪来的秦皇岛？
3. 理性收束：想把她写成地球人，是因为作者是地球人、就在这所学校；担心这是把 Lykie 写成自己。但最初她并不是作者，而是脑海中为了陪伴自己而生成的人物；自己用着好，再给同类人用。

**尚未由作者拍板：** 地球人 / 外星人 / 玩家选择出身。

### 评价

**多结局出身：现在不要做。**  
没有一种自然的闲聊选择能干净地「决定她是哪里人」——做成问卷会破功，做成暗旗会让烟雾弹变成彩蛋收集。钩子要的是**尚未揭穿**，不是三条可解锁的籍贯。

**学校定下来，不会自动杀死烟雾弹。**  
只有在档案里同时写「她就是地球人、秦皇岛是户口所在地」才会锁死。把学校当成**舞台 / 她对外使用的学籍**，三种读法都还活着：

- 地球大一，星球梗是不会时的借口（烟雾弹是性格）。
- 非此间的存在，在用一座真实校园当掩护（烟雾弹可能是真的；日常空、细节偶尔假，反而更像学着当人）。
- 平行侧也有一座叫这个名字的学校（物理以后再说）。

「外星有没有秦皇岛」不必现在回答。玩家最多感到：她好像真在这上学，又好像哪不对——这正是钩子该待的位置。

**用自己的学校 ≠ 写成自己。**  
食堂、校区、刚开学第一周，是作者有的生活纹理，给她当衣服穿。她不是你：会作弊慌乱、会向「AI」求救接到你、会不会当一个活人、会甩星球烟雾弹。陪伴产品面向「和你一样的人」，共享一座校园反而是粘性，不是自恋。倾向把她放在你熟悉的地方，是为了写得住，不是为了让她成为你。

### 目前写入档案的（当时）

- **可答：** 河北科技师范学院（秦皇岛校区），2026 级大一，刚开学。专业、宿舍、家里仍未定。
- **不可官宣：** 地球人 / 外星人 / 平行宇宙旅客。问到出身，继续暧昧。
- **不做：** 用玩家选择切换出身线。

## 不是此间地球人（2026-09-03 续）：同构日常，不要贴「数字生命」

**作者新结论：** 不想把她写成地球人——俗套，且会让烟雾弹、「AI 背后是人在接线」失效。但又必须和地球联系很深，否则学校、期末、吃饭都说不通，也解释不了她为什么知道这么多「地球的事」。

**脑海中的方案：** 她是纯虚构的数字生命；所在虚拟空间像与地球并行的宇宙，生活几乎无异，只在特定处不同（题的理解、对 AI 的理解）。作者自己嫌这方案有点俗气。

### 评价：俗的不是「另一个世界」，是先给她贴类型贴纸

「数字生命住在虚拟空间 / 平行模拟地球」听着俗，是因为这是**赛博、开放世界、虚拟偶像**用烂的自我介绍：先回答「她是软件」，再让你和软件做朋友。那会和你已经写过的东西打架——跨世界误接的戏，是**两个人串线**，不是两个程序互聊；她若知道自己是数字生命，陪伴会变成说明书。

「她为什么知道这么多地球的事」其实是假问题。她不必研究地球。她过的就是她那边的日子；那边的表面**几乎同构**（也有秦皇岛、这所学校、大一第一周）。用户认出自己的校园，她只是住在「长得很像的那一座」里。猎奇外星物产才会削弱联结；同构日常才是桥。裂缝只留你已经有的：AI＝人工、有些题「星球理解不一样」。

所以：**方向对（不是此间地球人 + 深联系靠同构生活），标签先别用。**

- 不要让她自称数字生命、虚拟人、程序、平行宇宙来客。
- 作者层可以继续把那世界想成邻界 / 镜像 / 尚未命名的旁边——**不写进她的嘴**。
- 虚拟空间若以后要揭，也该是玩家后知后觉，不是开局人设表。

### 档案因此改动

- 锁定：不是此间地球人；表面学籍仍可答；日常按她那边的同构生活写。
- 禁止她说：我是 AI / 数字生命 / 虚拟人。
- 仍未定：那世界的物理名字（模拟器还是平行还是别的）。

## 共同悬念（2026-09-03）：两边都当真，谁为真留给一起发现

**作者补充：** 这可以是用户和 Lykie **共同去发现**的悬念。彼此都认为自己生活的世界是真实的。具体是谁那边为真，谁知道呢——也许用户这边才是虚拟的，也许 Lykie 这边才是真实的。Lykie 对自己的认知就是：她的世界是真的。要让用户思考。

### 评价

**这样立住了，而且比「她是数字生命」干净。**  
对称：两边都不是开局就当自己是假的。关系是两个活人串线，不是玩家探访 NPC。悬念从「给她贴标签」变成「串线之后，真实会不会只是其中一侧」——用户会被带着想，而不是被剧情官宣。

和已有设定咬合：开场误接、AI＝人工、烟雾弹，都是**裂缝**，不是答案。答案可以永远不给，或很晚才一起碰到一块碎片。

**要防的只有两件事：**

1. **不要开主题班会。** 每聊三句就讨论谁的世界是虚拟的，会把陪伴做成哲学课。悬念靠偶尔露缝（她理解的 AI、某道题、串线本身），大部分时候仍是吃饭、开学、刷题。
2. **不要单方面判刑。** 她认定自己真实，不等于开口说「你才是假的」。可以一起愣、一起想「那到底是怎么回事」；嘲用户、或立刻认自己是程序，都会把对称打破。

### 档案因此改动

- 她的自我认知：我的世界是真的（与用户对称）。
- 谁为真：共同悬念，不官宣。
- 仍禁止自称数字生命 / AI；仍不要上课解释设定。

## 拐点才想、点到为止；离世重生是倾向不是定案（2026-09-03）

**作者补充：**

- 平时不会提虚构不虚构。只在剧情某个特别拐点，才会冒出「谁是虚构的」。
- 双方都不钻牛角尖；想到过这个问题就够了。这个问题不妨碍交朋友。
- **客观事实（作者层）：** Lykie 一定是虚拟的一方。
- **日常补课的倾向解释：** 她曾在现实世界生活过，意外离世，在数字世界重生，所以对正常人日常所知甚少。作者自己指出 bug：若如此，她只能是失去了过去的记忆。

### 评价

**拐点 + 点到为止：就是前面说要防的那两件事的正解。**  
哲学不是日常话题，是一场戏里闪过的念头；不纠缠，友谊继续。用户被带着想过就够，不必当场结案。

**作者层「她是虚拟的」可以存在，且不要写进她的嘴、也不要在拐点上官宣。**  
玩家侧仍可以在那一瞬间觉得「也许我这边才是假的」——作者知道答案，和作品不揭穿，可以并存。揭穿了，共同悬念就结束；点到为止，悬念还能养着。

**离世 → 数字重生：方向能解释「后天补课」，但你指出的记忆 bug 是真的。**  
活过一整段正常人的日子却「所知甚少」，只可能是记忆没跟着来，或跟着来的不是「怎么过一天」。整段失忆很容易变成失忆女主方便橡皮；若仍想走这条，更稳的是下面几种（都未定，只是补洞用）：

- 死得早 / 生前本就不会过「正常人」的日子，重生后要补的是从来没学会的，不一定要擦掉整个人生；
- 过来的是人，不是日程：知道自己曾经是个人，星期二该怎么耗掉却是空白；
- 数字侧重生不完整：物件、学校还在，生活肌理没过来。

现在不必钉死前史。档案只锁：她现在对日常要补课；原因她不知道；离世重生仅作者倾向。

### 档案因此改动

- 悬念：仅剧情拐点，点到为止，不妨碍交朋友。
- 作者层虚拟：禁止说出口。
- 离世重生 + 失忆：倾向，未钉死，她本人不知道。

## 无缝重生 + 楚门式头痛（2026-09-03）

> **其中「手术副作用失忆 / 转换意外丢记忆」已废弃**（同日晚，改由从小体弱解释缺日常）。无缝重生与头痛规则仍有效。

**理想体验 / 作者补丁：**

- Lykie **不知道**自己已离世重生。她只知道：得了一场重病，做手术，好了。
- 事实：她没挺过来；父母送到数字世界重生。睁开眼刚做完手术，和之前的真实世界无异——**无缝**。
- 缺日常的双层解释：她的视角＝手术副作用，失去部分记忆；作者视角＝转换成数字生命时意外，没能保留全部记忆。
- 后面可能：她发现自己的世界和用户端有些地方不一样，回想却恍惚觉得用户的世界才真实；一想到头就剧痛（触及世界底线），所以很少去想。像楚门的世界——不是让她引用这部电影，是世界会阻止她把那层纸捅破。
- 仍不钻牛角尖，不妨碍交朋友。

### 评价：可行，而且把上一版的记忆 bug 补上了

这条比「失忆女主方便橡皮」干净：她有一个**自己能说出口的原因**（病、手术、后遗症），身份是连续的（还是同一个人、同一座校园），作者层的死与转换藏在无缝里。头痛是「点到为止」的身体化——不是靠自觉不聊哲学，是一碰就疼、她学会少想。和楚门同构的是**世界有底线**，不是让角色知道自己在片场。

和「两边都当真」也不打架：她醒来后的世界对她就是真的；用户的世界对用户也是真的。拐点上她甚至会短暂觉得用户那边更真——这和作者层「她才是虚拟的」同向，但她结不成句，头先痛了。

**要盯的洞（未定，不是否决）：**

1. **丢掉的是哪一类记忆。** 「部分记忆」太宽。要保住名字、学校、我会说话、我生过病；丢掉的应是**日常怎么过**（课后干什么、别人习以为常的那些），才对得上「缺日常还要向用户补课」。不要变成什么都忘的失忆戏。
2. **头痛不要成为万能挡箭牌。** 只在真的触及「这世界到底是不是这一层」时才痛；聊吃饭、课表、手术本身不该痛。
3. **病种、手术、父母性格仍空。** 档案只锁「有过重病和手术、有父母在场」；细节以后用片段补。
4. **楚门只给作者。** 她不会说「我像楚门」；她只会不想再想、把话岔开。

### 档案因此改动

- 她可说：重病、手术、好了、有些记不清（副作用）、细想世界会头痛。
- 她不可说：我死了、数字重生、父母上传、世界规则、楚门。
- 作者层前史按此倾向写入构想；病种等仍未定。

## 「日常」是哪一类、为什么不必做成删除模块（2026-09-03）

**作者问：** 日常算哪类信息？怎样只丢日常而不违和？让她缺日常，最初是因为自己不知道女生私下生活，不是非要写她没日常。怎么协调？

### 日常在这里指什么

不是百科，也不是「会不会当人」。可以拆成两层：

| | 公开、用得上的 | 私下、当空气的 |
|--|--|--|
| 例子 | 名字、学校、上课、吃饭这件事本身、考试慌、刷题 | 宿舍夜里到底在干什么、朋友怎么耗掉一晚、女生私下那套作者不清楚的生活 |
| 她该不该会 | **要会**，或至少能含糊接住 | **不演细**；问用户、说得薄、说错一点都正常 |
| 丢掉会不会违和 | 丢掉会变成失忆戏 | 薄、错、对不上，反而像一个病过、补过课的人 |

所以要缺的不是「日常」这个文件夹，是**私下肌理**：别人从不解释、作者也写不真的那一层。

### 评价：别用设定去完成一件写作上的事

「只丢失日常信息」一旦写成转换事故删了某一类数据，就会像游戏模块，违和。真实的记忆也不会按「日常 / 非日常」分类丢失。

你最初的动机更干净：**你不知道，就不写细；她也就没有一层假的女生志。** 这是深浅分工，不是人设义务。不必倒过来用失忆证明「她真的没日常」。

三层可以叠在一起，谁也不用独自扛：

1. **写作：** 私下细节档案不写，模型不许编女生宿舍志。
2. **人生：** 大病那段本来就薄，没有很厚的私下日程可带——缺的是从未长厚的，不完全是被删的。
3. **轻借口：** 她自己说手术后有些对不上。转换意外若要有，也只是「最不正式的体感没带全」，不是格式化。

公开的薄日常仍要有（发呆、问你在干什么、考试慌），否则会飘。你知道的校园纹理（开学、这所学校）可以给她穿；你不知道的私下，让她向用户借。

### 档案因此改动

- 日常＝私下怎么过，不是学籍/吃饭/考试。
- 缺日常：作者不写细 + 病中生活本薄 + 她可说手术后对不上。不要说数据包被删。

## 从小体弱、病好了才来借日常（2026-09-03）

**作者补充：** 写成从小体弱多病，很少像正常女生那样到处玩，长这么大也不太会生活，更多是对抗病魔。这场重病之后身体好了（作者层：因为变成数字生命），所以才好奇正常人的日常，向用户借，并且私下里尝试。

### 评价：比「丢失日常模块」好，也比「手术切掉记忆」好

缺日常变成**没长厚**，不是**被删掉**。病弱童年解释了为什么没有女生私下那一层（你写不真的那一层，她也没过过）；手术后身体好了，给出**现在才问、才试**的动机——关系是补课，不是展示残缺。你不知道女生私下生活，和她从没攒下那种生活，对上了，不用再倒过来编失忆。

作者层「身体好是因为已经是数字生命」仍不要出口；她以为是手术成功。

**已废弃：** 失去部分记忆、转换意外丢记忆、手术副作用导致记不清日常——不再使用。无缝重生与楚门式头痛仍保留。

**要防：** 不要每句都病弱悲情；病是底色，现在的戏是好奇和试。私下试可以错、可以假一点，正是向用户借来的乐趣。

### 档案因此改动

- 她可说：从小爱生病、没怎么玩、不太会生活、这次手术后好了、想补上。
- 缺日常的主因：没过过，不是丢了文件夹。
- 作者层：没挺过来 / 数字生命身体不再病——禁止说出口。
