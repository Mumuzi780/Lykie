### 2026-09-14（导入页 Word 布局 + 主题跟随）

- **Word**：选定后收起大粘贴框，改为文件卡（清除 / 改用粘贴）；正文不在此页展开。

### 2026-09-14（题型总览 × 单题型样板）

- **流程**：输入 → **题型总览**（只显示题数/状态）→ **点进某题型选样板** → 回总览 → 预览 → 入库。

- **归并池**在样板页；切不准走「对照原文」兜底（清掉池子腾版面）。
- **微调**：默认隐藏输入框；「用作样板」三选一（确认 / 取消 / 微调）；上方「系统没切准」也可进微调或对照原文。

## 一、第一版（v1）已实现功能

以下为 **v1 起可对用户交付** 的能力底座（v2/v3 在其上叠加）。未做项见各版说明与「下一版候选」。

### 1. 账号与数据隔离

- 邀请制登录（无公开注册）：`/login`、`/logout`；会话约 30 天。
- 开号：`python add_user.py <用户名>`；`add_user.py list` 列账号。
- 每用户独立目录：`data/users/<用户名>/bank.json`、`lykie_state.json`、`sa_progress.json`。
- 首个账号可迁入旧版全局 `data/bank.json` / `lykie_state.json`；之后账号空白起步。

### 2. 客观题库 · 斩题背题

- **入口**：主界面 `/`；侧栏切换题库；题库 `mode = objective`（或非简答）。
- **导入**：见 v3 [`版本更新-v3.md`](版本更新-v3.md)；入口 `/import`。
- **题型**：选择题 / 判断题 / 填空题。
- **抽背**：间隔重复（按抽卡次数倒计时）；对/错反馈；「斩」移出题池；进度条与重置进度。
- **管理**：重命名 / 删除题库；查看列表；增删改单题；卡片显示正确率等 meta。

### 3. 简答题库 · 无脑训练

- **入口**：侧栏选中简答库（`mode = short_answer`）→ 主区切到简答训练。旧 `/sa` 重定向到 `/`。
- **种子库**：`教资科二简答-短题`（脚本安装）。
- **学习阶段**：热身多选 → 特色（挖空 / 连线等）→ 答案选题干 → 无提示默写。
- **复习（最小记忆曲线）**：自然日间隔 1→2→4→7→14；按批复习等。
- **进度**：`sa_progress.json`；可重置；可编辑分点关键词。

### 4. Lykie 角色

- 右侧面板闲聊；刷题不依赖 API Key，聊天需服务端 `.env`（`LYKIE_*`）。
- **问问 Lykie**：针对当前题讲解。
- 记忆、人工监督、开场剧情 MVP、探头等——详见相关文档。

### 5. 界面与体验

- 品牌顶栏；浅色 / 深色（`localStorage`）；移动竖屏抽屉与沉底题卡。

### 6. 运行与部署（工程侧）

- 本地：`python app.py`；依赖 `requirements.txt`；宝塔相关在 `scripts/`、`dist/`。

### 7. 长期未做 / 未封顶（跨版本）

- 站点垫付识图 / 站内 OCR；用户自备 Key 的设置页。
- 公开注册、找回密码、管理后台。
- 客观与简答混进同一 `questions` 列表。
- 简答长题全集等试感后续；桌宠与长线剧情系统。
- 专业共享题库赛道。
