## 一、第一版（v1）已实现功能

以下为**当前可对用户交付**的能力，不含愿望清单。未做项单独列出。

### 1. 账号与数据隔离

- 邀请制登录（无公开注册）：`/login`、`/logout`；会话约 30 天。
- 开号：`python add_user.py <用户名>`；`add_user.py list` 列账号。
- 每用户独立目录：`data/users/<用户名>/bank.json`、`lykie_state.json`、`sa_progress.json`。
- 首个账号可迁入旧版全局 `data/bank.json` / `lykie_state.json`；之后账号空白起步。

### 2. 客观题库 · 斩题背题

- **入口**：主界面 `/`；侧栏切换题库；题库 `mode = objective`（或非简答）。
- **导入**：Word `.docx`（`/api/import`）；粘贴文本可预览再确认（`/api/import_text`）。
- **题型**：选择题 / 判断题 / 填空题（解析规则自动识别）。
- **抽背**：间隔重复（按抽卡次数倒计时）；对/错反馈；「斩」移出题池；进度条与重置进度。
- **管理**：重命名 / 删除题库；查看列表；增删改单题；卡片显示正确率等 meta。

### 3. 简答题库 · 无脑训练

- **入口**：侧栏选中简答库（`mode = short_answer`）→ 主区切到简答训练（与客观题同一壳，非平行产品页）。旧 `/sa` 重定向到 `/` 并尽量选中简答库。
- **种子库**：`教资科二简答-短题`（脚本安装，非整站用户自助导入流水线）。
- **学习阶段**：热身多选 → 特色（挖空 / 部分题连线与半边挖空）→ 答案选题干 → 无提示默写。
- **并列挖空**：默认有序；清单类可题级勾选无序；相同文架空可成组无序。
- **复习（最小记忆曲线）**：自然日间隔 1→2→4→7→14；到期优先复习默写，可降挖空；再挂可退回学习；复习按批（每批最多 2 道，刷完一组学习再开下一批）。
- **进度**：`sa_progress.json`；状态栏区分学习 / 到期 / 间隔中 / 本批余量；可重置简答进度；可编辑分点关键词。

### 4. Lykie 角色

- 右侧面板闲聊；刷题不依赖 API Key，聊天需服务端 `.env`（`LYKIE_*`）。
- **问问 Lykie**：针对当前客观题或当前简答题干讲解（简答模式已同步按钮与探头）。
- 记忆：日常 facts、口吻 `style_notes`、纠正回路；面板气泡可持久化。
- 人工监督：气泡 👍 / 👎（见 `Lykie人工监督.md`）。
- 开场剧情 MVP：`fragment_01` 自动播放 / 重温开场（见 `开场剧情接入.md`）。
- 探头（peeker）点按开合面板；客观题与简答共用探头。

### 5. 界面与体验

- 品牌顶栏：Lykie + 副标题（背题 / 简答随模式切换）。
- 浅色 / 深色：左上角太阳（实心）/ 月亮（线稿）切换；偏好存 `localStorage`。
- 移动竖屏：题库抽屉；题卡沉底；Lykie 默认可收起；简答与登录页有竖屏适配。
- 登录页品牌化（字体与青绿主色）。

### 6. 运行与部署（工程侧）

- 本地：`python app.py` 或启动 bat；优先 Waitress，否则 Flask；默认 http://127.0.0.1:5000/。
- 依赖：`requirements.txt`；打包：`pack_for_server.py`；宝塔相关脚本在 `scripts/`、`dist/`（运维用，非终端用户功能）。

### 7. 第一版明确未做 / 未封顶

- 站点垫付识图 / 站内 OCR；用户自备 Key 的设置页（当前密钥在服务端 `.env`）。
- 公开注册、找回密码、管理后台。
- 客观与简答**混导入校验**（已约定按题库隔离；导入拒混搭尚未做）。
- 简答长题全集、碎点默写过渡、疲劳节奏等（试感笔记中的后续方向）。
- 桌宠、主动催题、特质自动演化；开场剧情以外的长线故事系统。
- 专业共享题库赛道。
