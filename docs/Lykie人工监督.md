# Lykie 人工监督（点赞 / 点踩）

在自由聊中，评价按「对用户**这一轮**的整次回复」：

- 用户可以**连发多句**：发出一句后若 3 秒内输入框又出现文字，Lykie 会继续等；输入框空着超过 3 秒才回一轮（不问答「问问 / 纠正」）
- Lykie **一次回复**可能拆成多条气泡；👍 / 👎 **只出现在该次连发的最后一条**
- 她也可以选择**先不回**（面板上出现淡色「（先不回）」），仍可点赞/点踩做监督
- **点踩**：保存监督案例后，**回退到你提问之前**，输入框带回原话，可改口或原句重发让模型再生成
- 点赞：记整组，只提示一次「已记住」

不要对每一句短气泡分别训练。

测试补档案时（`lykie/self.txt` 里 `严格模式：开`）：问到她档案里没有的私事，她不应现编，面板会出现橙色「请补全」；绿色「档案用了」表示那一轮真读了档案。补完档案再说一遍即可。

## 清到开场后

工具栏 **「清到开场后」**：把 `chat_tail` 与面板记录重置到开场刚结束（保留本账号 `facts` / `portrait` / 全站监督 / `flags`）。方便反复测自由聊。

点踩写入全站 `data/lykie_shared.json`，换账号仍然生效。每个账号另有一份 **画像**（`portrait`）：记对方有没有羞辱过她，以及开场记下的名字。「清到开场后」还在；**「清空记忆」会清掉画像和名字**。这不是监督案例，不会挤掉 25 条上限。

## 聊天记录持久化

面板气泡写入该账号 `data/users/用户名/lykie_state.json` 的 `panel_log`；重启后若开场已完成，会自动还原。模型上下文仍用 `chat_tail`（最近约 40 条）。口吻与监督不在这份账号文件里。

## 连发与沉默

理想节奏示例：

```
用户：累呀，所以我来找你说说话
用户：你在干嘛呀？
Lykie：我刚在收拾东西呢
Lykie：你呢？
```

点踩时：

- 好范例按 Lykie 视角写整轮（多行短句）——写入监督记忆，供以后注入 prompt
- **若理想是先不回**：好范例**留空**，或写一行 `[不回复]`，并在点评里说明原因
- 面板上该轮用户话 + 她的回复会被撤掉，便于重问

## API

- `POST /api/lykie/feedback`（点踩默认 `rollback: true`）
- `POST /api/lykie/chat_reset_opening` — 清到开场后
- `POST /api/lykie/panel` — `{ messages: [{role,text,...}] }` 保存面板
- `GET /api/lykie/state` — 含 `panel_log`

## 注意

- 这是**本地记忆监督**，不是微调模型权重。
- 案例过多时只注入最近若干条（默认 6）。
- 开场剧情播放中不显示 👍👎，也不持久化中间帧。
- 「问问 Lykie / 纠正」仍是发完就回，不走连发等待。
