# Lykie V3.1 更新说明

> 发布日：2026-09-15

---

## 一句话

**斩题更有手感，收件箱能看见版本更新；二周目起斩题更轻快。**

---

## 你多了什么

1. **斩题进度条分档**：跨过约 25% / 50% / 75% / 100% 时，短句鼓励 + 闪电充能，播完即消失。  
2. **斩满过场**：进度条上移到竖直中心 → 透视远去；结算从偏大贴脸缩小到位（错开播，少抢注意力）。  
3. **二周目起斩题更松**：答对一次即可斩；答错需再对后才能斩（一周目规则不变）。  
4. **登录标语**：改为「把学会的，变成自己的。」  
5. **收件箱**：分享通知与版本更新同一铃铛入口；点更新可看本页短说明。
