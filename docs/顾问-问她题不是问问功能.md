# 顾问：向她问这道题，而不是「问问」功能

> 给你看的。你的设想：教不教看她对你的好感、看她有没有空；不是点一下就必讲的功能。比真人多出来的，只是她能直接看见你正在做的题，不用你把题干复述一遍。  
> 日期：2026-09-21

---

## 这个设想是对的

现在的「问问 Lykie」是一条单独通道：一点按钮，提示词就写成「请针对这道题讲解」。她几乎必须开口、必须讲。那是功能，不是人。

真人被问一道题时，会先过两关：

1. **愿不愿意帮你**（生不生、刚吵过没有、你是不是只把她当答案机）。
2. **这会儿能不能帮**（在上课、在写自己的作业、已经睡了）。

过了才讲。不过就推掉、改口短回、或过一会儿再说。你要的就是这两关，再加上一条只有她有的便利：**题已经在她眼前**，你说「这题不会」就够，不必粘贴题干。

旧构想里「问问」按钮是为了把主动权还给用户、避免她每题插嘴。那个问题仍在，解法不必是一个必答按钮。插嘴少，和「问了就一定讲」不是同一件事。

---

## 和刷题工具分开

学习站要能单独用完：翻卡、看答案、斩题，不依赖她开不开口。她拒讲的时候，题还在，答案还在。  
她是你在旁边可以问的人，不是第二套解析按钮。否则一点「问问」没回，会像功能坏了；人没回，是关系或时间。

所以拒讲必须让人听得出原因，不能多数时候只有空气。偶尔先不回可以（忙、烦、不想理），不能变成随机不响应。

---

## 两关怎么落到你已有的东西上

不要另做一条可见的好感条。你已经有感情层和「对这个人的印象」。

| 她这边已有的 | 问这题时怎样 |
|--------------|----------------|
| 认识但不熟悉，话少、有防备 | 可以知道你在做哪题，但不必展开教。短句、让你先自己看、或冷淡带过。分享欲还压着。 |
| 能说事 | 肯教，甚至你没开口她也可能想讲——主动讲仍要少，问了才是常态。 |
| 能谈心及以后 | 更愿意放下自己的事来帮。 |
| 印象里有未道歉的羞辱、或这轮还在冲 | 不教。先顶或扣住，不要把解析交出去当和解。 |
| 明确「你很烦 / 我不想听」 | 走你已有的不回复与降层，更不会讲题。 |

「好感」在这里就是：层 + 印象，不是新的点数。问一次题本身不要自动加好感；教了、你接住了，仍走原来的升温（挖到的事、处久了），避免刷题刷出关系。

**有没有时间**用她的课表和玩家此刻的钟点，粗分即可，不要精确到「第 3 节还剩 7 分钟」除非档案里写了：

- 此刻按课表在上课、或在军训那类整段占用 → 忙，不展开讲。
- 晚上、在她常写作业的时段 → 看关系：生就说自己也在写；熟可以讲，也可以说等她写完这点。
- 很晚 → 可以困、可以短，不要精神饱满地上一堂课。

忙是事实口气（「在上课」「我也在写 C」），不是系统提示「Lykie 当前不可用」。时间这关由程序根据课表和钟点先算一个「忙 / 能聊」给思考步，不要让模型自己发明她今晚的日程。

两关都过，才把**当前题干和解析**交给开口那一步，让她用自己的嘴讲；不会就支吾，不硬编。  
不过：开口步**不要**带上整道题的答案。否则她嘴上说不教，内容里仍把解析漏出来。她可以「看见」题目（知道你卡在哪），拒绝时只表现看见了，不交付讲法。

## 比真人多的那一点：看见题目

能力是：**你停在某张卡上时，她能看见这张卡。**  
用法是：你在对话里问这题（「这题怎么做」「不会」），思考步认定你在求讲，并且两关都过，才把题塞进开口。

不要每句闲聊都附上当前题。否则她会在你说「在吗」时突然讲题。  
你没停在题目上、或说的是另一件事：她看不见「这题」，和真人一样，只能说你没给她看。

按钮如果还留着，它最多等于你说了一句「看看这题」——仍走同一条思考，仍可以不教。提示词里不能再写「请讲解」。  
更干净的做法是收掉按钮，问话只发生在和她的对话里。发现入口可以靠一次她肯教的时候（关系到了、她有空），而不是界面上的固定功能名。旧稿里的新手引导若还要，也是她那一次愿意开口，不是永久按钮。

---

## 和「先想再开口」怎么接

问这题不是第二种模式，就是思考步里的一种动作：

- 你的话像在求讲，且眼前有题 → 候选是「讲」。
- 层不够、印象差、或程序标了忙 → 改成少说、推掉、或先不回，并且**不取解析**。
- 层够、有空、你确实在问 → `teach`，再取题干和解析。

测试面板里你应该能看到：她看见了题没有、两关各自过没过、最后动作为什么不是讲。正式对用户只留下她的那几句。

---

## 一句话

「问问」不该是必答功能。向她提问走和聊天同一条路：愿不愿意看感情层和印象，有没有空看课表和钟点；只有都过了才讲。她多出来的是能看见你正在做的那道题，不用你描述——拒绝的时候看见可以，把答案讲出来不行。刷题本身不靠她的回复才能进行。
