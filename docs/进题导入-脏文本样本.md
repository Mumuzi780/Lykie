> 一点一点收集「简单脏文本」套路，供 `/import` 样板切块与噪声过滤做手工/脚本回归。  
> 策略见 [`进题导入-设计草案.md`](进题导入-设计草案.md)。  
> **纯文本正文**放在 [`tests/fixtures/import/`](../tests/fixtures/import/)；本文只做目录与预期说明。

最后整理：2026-09-13

---

## 怎么续加

1. 在 `tests/fixtures/import/` 新增 `dirty_choice_00N.txt`（只放原文，勿改既有编号文件含义）。
2. 在本文「样本目录」加一节：噪声点、预期题数、建议样板（可复制第 1 道完整题）、备注。
3. 本地冒烟（可选）：

```bash
python -c "from pathlib import Path; from lykie.import_exemplar import parse_by_exemplar
text=Path('tests/fixtures/import/dirty_choice_001.txt').read_text(encoding='utf-8')
# 用文件里第一道完整题当样板时，请手工截一段；或见下节「建议样板」
"
```

原则：只收**已知、可复现**的脏法；每条样本写清「期望还能认出几道」，不要默默改旧样本预期。
