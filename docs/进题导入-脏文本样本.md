最后整理：2026-10-10

## 怎么续加

1. 在 `tests/fixtures/import/` 新增 `dirty_choice_00N.txt`（只放原文，勿改既有编号文件含义）。
2. 在本文「样本目录」加一节：噪声点、预期题数、建议样板（可复制第 1 道完整题）、备注。
3. 本地冒烟（可选）：

```bash
python -c "from pathlib import Path; from lykie.import_exemplar import parse_by_exemplar
text=Path('tests/fixtures/import/dirty_choice_001.txt').read_text(encoding='utf-8')
# 用文件里第一道完整题当样板时，请手工截一段；或见下节「建议样板」
"
```

原则：只收**已知、可复现**的脏法；每条样本写清「期望还能认出几道」，不要默默改旧样本预期。

### xuexitong_html_001–004 — 学习通网页另存 HTML（DOM 直解析通道）

| 项 | 内容 |
|----|------|
| 文件 | [`xuexitong_html_001.html`](../tests/fixtures/import/xuexitong_html_001.html) · [`002`](../tests/fixtures/import/xuexitong_html_002.html) · [`003`](../tests/fixtures/import/xuexitong_html_003.html) · [`004`](../tests/fixtures/import/xuexitong_html_004.html) |
| 来源 | 三份学习通「作业详情」页另存 HTML 裁题生成（仅保留题目主块，div 平衡配对裁切）；004 为 003 的截断片段版（从 questionLi 起、截尾不闭合） |
| 构成 | 001：36 单选 + 10 填空（46 块）；002：9 单选 + 9 填空 + 2 简答 + 1 论述（21 块）；003：4 单选 + 4 多选 + 3 填空 + 4 判断（含解析）（15 块）；004：1 单选 + 1 多空填空 + 1 判断 + 截断残块 |
| 预期 | `lykie/import_dom.parse_xuexitong_html`：choice 存字母串（`A` / `ABC`）、judge 归一 `对/错` 且 `options: []`、fill 多空以全角 `；` 连接、short_answer 出 points 结构；题型读 `span.colorShallow` 并剥 `, N分`；`needs_answer_confirm` 一律不设；截断残块跳过计数、不猜 |
| 状态 | 2026-10-10 新增；配套 `lykie/import_dom.py`（标准库 HTMLParser 状态机，零新依赖），接入 `/api/import_text`（命中标 `platform: "xuexitong-html"`，零题回落纯文本管道标 `"xuexitong-html-fallback"`）；与一期文本管道交叉验收 46/46 题语义一致 |

DOM 陷阱备忘（维护解析器时注意）：

- 题目容器 class 全是 `singleQuesId`，**不能靠容器 class 区分题型**；题型必须读 `span.colorShallow` 文本，且存在 `, N分` 后缀与「选择题」（非「单选题」）变体。
- 选择/判断答案 = 非 dl 语境的 `span.rightAnswerContent`（choice 是字母、judge 是汉字「对/错」）；填空/简答答案 = `dl.mark_fill.colorGreen` 里逐 `dd.rightAnswerContent`（fill 带 `(k)` 编号前缀需剥、尾部常挂 `<br>`；简答是按行分点的长文）。
- 噪声块须跳过：`element-invisible-hidden`（页面隐藏的冗余答案区）、`mark_score`、`aiAssistant`、无 `colorGreen` 的 `mark_fill`、script/style。
- `qtContent` 有带 `<p>` 包裹与直排两种形态；解析按标签深度计数定位，不依赖固定层级。
