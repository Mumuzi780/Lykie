# 剧情分支编辑器（独立工具）

与刷题站（Flask）解耦的可视化对话树编辑器，基于 React Flow，适合画底特律式大分支。

## 启动

双击仓库根目录：

- **`启动背题助手.bat`** → http://127.0.0.1:5000/
- **`启动剧情编辑器.bat`** → http://127.0.0.1:5173/（首次会自动 `npm install`，并打开浏览器）

或手动：

```bash
cd story-editor
npm install
npm run dev
```

浏览器打开终端提示的地址（默认 `http://127.0.0.1:5173/`）。

## 节点类型

| 类型 | 说明 | 时间字段 |
|------|------|----------|
| Lykie | 角色一条消息 | `delayMs`：默认每字 **400ms**（标点不计；纯符号 **0.5s**） |
| 玩家选项 | 一组选项；每项一个出线；另有「超时」出线 | `timeoutMs`：限时，0=不限 |
| 自由回复 | 玩家自由打字；预设若干分支出线；**运行时由 Lykie 判定走哪条**（编辑器不写判定） | 无 |
| 系统 | 系统提示文案 | `delayMs`：默认 **0.5s**，不受打字速度影响 |
| 等待 | 纯等待（思考、交卷等） | `delayMs`：**不含打字**；思考时间单独加在这里 |
| 结束 | 结局/下线 | 无 |

## 打字速度（仅 Lykie）

- 有实质文字：**每字 400 ms**（标点、空白不计）
- 纯符号 / 空文案：默认 **500 ms**
- 系统提示：默认 **500 ms**（不按字数）
- 思考/交卷：用「等待」节点，不写进 Lykie 延迟

## 操作

- 左侧点击或拖到画布添加节点
- 从节点右侧圆点拖线到下一节点（左入右出，适合从左向右写）
- 右侧改文案与毫秒/秒；「设为起点」标记预览入口
- 顶栏：新建 / 导入 JSON / 导出 JSON / 预览
- **Ctrl+Z** 撤销 · **Ctrl+Y**（或 Ctrl+Shift+Z）重做
- **点击连线** 后按 **Backspace / Delete**：只删除连线，接口保留
- **选中节点** 后按 **Backspace / Delete**：删除节点及其连线
- **Ctrl+S** / 顶栏「保存」：保存到浏览器本地；**下次打开默认载入**这份草稿
- 有改动后 **无操作 30 秒**自动保存；另 **每 5 分钟**自动保存一次
- **在空白处拖拽**：框选多个节点；拖动选中节点可一起移动
- **Shift + 点击**：加选/减选节点
- **空格 + 拖拽**：拖动画布（不按空格时为选择模式，不会拖动画布）
- **左 Alt + 左键** 拖动圆点：沿节点边缘移动接口（连线会跟着走）
- 小地图与滚轮缩放适合大树
- 「导出」仍可下载 JSON 文件；「导入」从文件载入

## JSON 格式

导出结构含 `id`、`title`、`startNodeId`、`nodes[]`、`edges[]`。  
`choice` 的边：`sourceHandle` 为选项 id，或 `"timeout"` 表示超时分支。  
`free_reply` 的边：`sourceHandle` 为分支 id（`data.branches[].id`）；节点数据含可选 `prompt` 与 `branches[]`。  
普通节点出线 handle 为 `"out"`。

此 JSON 供以后游戏 runner 使用；**当前未接入刷题页**。

## 与刷题站关系

| 项目 | 路径 | 启动 |
|------|------|------|
| 背题 + Lykie | 仓库根目录 `app.py` | 双击 `启动背题助手.bat` 或 `python app.py` |
| 剧情编辑器 | `story-editor/` | 双击 `启动剧情编辑器.bat` 或 `npm run dev` |

可把导出的 JSON 放到 `data/stories/` 备查，编辑器本身用下载/导入文件即可。
