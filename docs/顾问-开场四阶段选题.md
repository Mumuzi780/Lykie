# 顾问备忘：开场按「入学心态四阶段」选题

> 作者方案（2026-09-20）：按上大学不同心态阶段出不同开场问题。  
> 与已锁理想对齐：**日子跟玩家屏幕真实日期走**；开场手写；AI 错解 → 世界不同。  
> 本文评价四阶段真实性、哪些适合当「第一砸」、怎么落地成多开场而不炸制作量。

---

## 1. 总评：阶段划分是对的，用法要分清

你列的四段，和国内大一（尤其秋季入学）问 AI / 问学长的心态曲线**高度吻合**：

| 阶段 | 心态 | 你举的例子 | 现实频率 |
|------|------|------------|----------|
| 1 刚开学 | 懵、怕踩规矩 | 校园卡、军训体检、上课收不收手机、挂科后果 | 极高（短窗） |
| 2 开始上课 | 被课砸到、术语不清 | C/高数题；专业课 vs 水课 | 极高 |
| 3 基本适应 | 开始管身体与节奏 | 保持身材、饮食调整 | 中（更常问小红书/同学，也会问 AI） |
| 4 期末周 | 焦虑速通、甩题 | 速通高数/四六级；原题砸给 AI 教 | 极高（短窗） |

**建议定性：**

- 这四套是 **「日历选开场皮」**，不是四种人设。  
- **骨头共用一套**：误接 → 不像人工 AI → 世界不同 → 互问一点 → 落「认识但不熟悉」。  
- 换的只是**第一砸的问题 + 前几句口吻**，不要写成四个完全不同的故事。

这样既满足「日期对齐」，又不会让制作量按 4 倍爆炸。

---

## 2. 和档案课表的咬合（选皮时用）

她侧（河北科技师范·秦皇岛，2026 秋）：

- 前几周：开学事宜 + 军训；许多课 **第 4～5 周**才按课表上。  
- 课表备注另有第 10 周军事训练——以档案为准，开场选皮时 **「军训/懵懂」窗**主要落在学期头，不要和玩家日历硬拧。  
- 有课之后：C、高数、英语等进入阶段 2。  
- 期末：阶段 4。

规则建议（给主仓/剧本）：

```
用玩家本地日期 → 映射到她本学期的「周次感」
→ 选 opening_skin ∈ {enroll, coursework, settled, finals}
→ 加载同一故事骨架 + 该皮的第一问与若干气泡
```

若某日落在模糊带（刚开课 / 快期末）：**优先选紧急感更高、更像「打开 AI」的那一皮**（通常 2 > 1，4 只在明确期末窗）。

## 3. 四阶段逐项：适不适合当「开场第一砸」

### 阶段 1 · 懵懂规矩题 — **适合当皮，且很贴「日期对齐」**

例子：校园卡该不该办、军训要不要体检、上课收不收手机、挂科有什么后果。

| 优点 | 注意 |
|------|------|
| 紧急感来自「怕做错」，很像找人工 AI 问政策 | 答案在两边世界可能真不一样 → **错解接口极好** |
| 不依赖作者写细宿舍志 | 一问一答容易「客服说明书」；要快切到「你回得不像 AI」 |
| 复读生设定：她可能比纯萌新多懂一点，但仍会核实 | 不要写成啥都不知道的吉祥物；可带一点「我复读过但大学这边还不熟」 |

**开场钩子质量：高。** 尤其玩家若在 9 月前后首启。

### 阶段 2 · 上课 + 题 + 水课 — **最推荐作为默认皮 / 长窗皮**

例子：C 题、高数题；「什么是专业课，什么是水课」。

| 优点 | 注意 |
|------|------|
| 与专业、志向（想当 AI 背后的人）、学习站产品都咬合 | 纯讲题会滑回旧砸题稿；重点仍是错位，不是交卷 |
| 「水课」类问题带价值判断，真人回复很容易露馅 | 题不要太长；手写剧本里题是道具 |
| 一年中占比最长 | 同一皮内可轮换「今晚 C 卡住」vs「这课算不算水」 |

**开场钩子质量：最高（默认）。**

### 阶段 3 · 身材 / 饮食 — **可作皮，但不建议当主推第一砸**

例子：大学怎么保持身材、饮食习惯怎么调整。

| 优点 | 风险 |
|------|------|
| 适应期真实会问 | 紧急感弱，不像「打开人工 AI 交差」 |
| 可薄触「手术后身体好了、想补正常生活」 | 易写成万能减肥顾问；且碰身体话题，开场阶段偏早 |
| | 她吃面不吃米、讨厌螺蛳粉等锚可以后来用，**第一句不必上身材** |

**顾问建议：** 阶段 3 更适合：

- 开场皮的**第二问**（正题错接之后新鲜感多问），或  
- 开场结束后的日常日历语气，  

而不是唯一第一砸。若坚持当第一砸：改成更「决策/怕做错」的薄问，例如「食堂老吃面正不正常」「体育课要跑多少」——仍生活，但更像问规矩/信息，而非健身教练。

### 阶段 4 · 期末速通甩题 — **适合短窗皮，戏剧强，勿当全年默认**

例子：怎么速通高数/四六级；甩题让 AI 教。

| 优点 | 风险 |
|------|------|
| 最像旧稿的辨识度与肾上腺素 | 与「勿锁死期末」冲突——**只能日历命中才用** |
| 甩题教 = 人工 AI 本职，错接反差大 | 易重新变成作弊惊悚片；弱化生死，强化「这人怎么这么怪」 |

**开场钩子质量：高（仅期末窗）。**

## 4. 推荐落地形态（制作量可控）

### 骨架（写一次）

1. 她砸来「本皮第一问」（短、脏）。  
2. 你回得不像接线（追问、扯远、暴露你那边常识）。  
3. 她察觉不对 → 世界不同可摊开。  
4. 新鲜感多问一点（可从**其它阶段题库抽 1 句当闲聊**，增加活人感）。  
5. 互报姓名等 → end → 认识但不熟悉。

### 四皮（各写薄）

| skin id | 日历 | 第一砸优先 |
|---------|------|------------|
| `enroll` | 学期头 / 军训开学窗 | 规矩题 1 条（你列的四选一即可） |
| `coursework` | 有课的长窗（默认） | C 或高数小卡点，或「这算水课吗」 |
| `settled` | 适应期（可选，可并入 coursework） | 生活薄问；或不用独立皮 |
| `finals` | 期末窗 | 速通 / 甩题，弱化交卷死刑 |

**制作建议：** MVP 先做 **`coursework` + `enroll`** 两皮；`finals` 第三；`settled` 可并入日常而非独立开场。

### 不要做的

- 四个完全不同的人物弧光。  
- 无日期时随机抽皮（会破坏「同一天」幻觉）。  
- 阶段 3 写成整段减肥剧。

## 5. 对你原列表的微调建议

| 你的原题 | 建议 |
|----------|------|
| 校园卡该不该办 | 留；错解可走「你们那边还有校园卡这套吗」 |
| 军训要体检吗 | 留；注意与课表军训周次一致 |
| 上课收手机吗 | 留；很日常 |
| 挂科有什么后果 | 留；略吓，适合懵懂，勿恐吓玩家 |
| C/高数题 | 留；当默认皮主力 |
| 专业课 vs 水课 | **强烈建议留**——比纯题更像真人，也更好拐世界不同 |
| 保持身材 / 饮食 | 降为第二问或日常；开场慎作第一砸 |
| 速通高数/四六级 + 甩题 | 仅期末皮；四六级大一上是否已急，可按校历调（可改成速通高数/英语） |

## 6. 与「想当 AI 背后的人」的轻回声

任意一皮在中后段（非第一句）可加一句志向，尤其阶段 2/4：

- 她正在**用** AI；  
- 她以后想**当** AI。  

错接的人是你 → 职业幻想碰到活人。一句足够，不要演讲。

---

## 7. 一句话结论

**四阶段选题：内容方向正确，应做成「按玩家日期选开场皮」，共用误接骨架。**  
默认主推阶段 2（题 + 水课）；阶段 1、4 按短窗启用；阶段 3 更适合当后续口气或第二问，不宜单独扛开场第一砸。
