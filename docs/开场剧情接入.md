# 开场剧情接入（MVP）

背题助手右侧 **Lykie 面板** 兼作剧情信箱。

原则（2026-09-23 起测）：开场**不用手写整段剧本**，用关键节点约束大模型走向。第一句仍可定稿。旧稿 `fragment_01` **保留勿删**，且**不自动播**。见 [`角色与剧情构想.md`](角色与剧情构想.md)。

## 2026-09-23 测：关键节点 1（不用手写整段剧本）

现行测试：**不用** `fragment_01` 自动播。作者点面板「测开场」才进入节点 1。第一句仍是定稿（不走模型），之后用节点约束大模型走向。

1. 她发出：「以前我一直想象大学会是很明亮丰富的…总是会有一点失落，怎么办？」
2. 对方连着短句（**句子结构**），或说出半截亲身经历 / 具体日子（**内容**，没展开也算像人），她可以察觉「不太像 AI」。两条可以同时成立，面板会记下是结构、内容，还是两者都有。空洞鸡汤单独不算。察觉之后应好奇去接那件事，不要审讯。
3. 长时间不回（测试默认 45 秒；输入框有字会暂停）：先发「卡了吗？」并重发问题；再等仍不回则不再催，关系停在开局。
4. 冷场之后对方主动找来，也算察觉线索（AI 通常不会自己先开口）。
5. 察觉之后**仍停在开局**，后面节点还没开始。旧 `fragment_01.json` **保留勿删**。

API：`POST /api/lykie/opening/start`、`POST /api/lykie/opening/nudge`；`GET /api/lykie/state` 含 `opening`。

## 试验台（最少提示词）

正式闲聊层太多、互相打架时，用 **`/lab` 开场试验台**（顶栏「试验台」）：

- 只接同一个大模型，**不读**正式记忆、口吻、监督、开场节点程序。
- 左侧分层：开关、上移/下移（越靠上越先写入）、改文案。默认只开「短核」和「开场情境」。
- 可加「思考步」（先低温 JSON 再开口）、「实时时间」、自定义层。
- 「由她先说第一句」发出定稿失落句，专门测开场。
- 展开「本轮实际写入的系统提示」看字数和拼出来的全文。

在这里用尽量少的层试出效果，再决定哪些进正式开口。

## 行为（runner 能力仍可用）

1. ~~未完成开场 → 加载故事 JSON，面板播剧本。~~ **现行：不自动播旧开场。**  
2. Lykie / 系统气泡按 `delayMs`；`wait` 可跳过等待。  
3. 选项芯片；大意匹配；限时走 `timeout`。  
4. 到达 `end` → 写完成 flag、可选 `player_name` → 自由聊。**不再写欠人情。**  
5. ~~可「重温开场」（reset）。~~ **现行：重温按钮隐藏；点击提示旧开场已下线。**

剧情进行中禁用「问问 Lykie / 纠正」；**不调用** LLM。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/story/fragment_01` | 返回 `{ ok, graph }`（旧稿仍可读） |
| GET | `/api/stories` | 故事 id 列表 |
| POST | `/api/story/complete` | `{ story_id, player_name?, ending? }` — 勿再写欠人情 |
| POST | `/api/story/reset` | 重开（测试） |
| GET | `/api/lykie/state` | 含 `flags`、`story_pending`、`opening` |
| POST | `/api/lykie/opening/start` | 作者测节点 1：钉开局并发出定稿第一句 |
| POST | `/api/lykie/opening/nudge` | 长时间不回：催「卡了吗？」并重发；再等则停 |
