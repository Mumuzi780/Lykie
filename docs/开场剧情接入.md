# 开场剧情接入（MVP）

背题助手右侧 **Lykie 面板** 兼作剧情信箱：未完成片段 01 时自动进入剧本模式；结束后切回自由聊。

## 行为

1. 首次打开（`flags.fragment_01_done` 为假）→ 加载 `data/stories/fragment_01.json`，在面板播开场。
2. Lykie / 系统气泡按 `delayMs` 出现；`wait` 可点 **跳过等待**。
3. 到选项时出现 **芯片**：点击填入输入框，可改字再发送。
4. 发送时按「大意」匹配选项（点过的芯片优先）；匹配不上则提示拉回，不推进。
5. 限时选项超时走 `timeout` 边。
6. 到达 `end` → 写入 `fragment_01_done`，可记 `player_name` 与「欠人情」fact → 自由聊。
7. 完成后工具栏出现 **重温开场**（会 `POST /api/story/reset` 并清空面板消息）。

剧情进行中禁用「问问 Lykie / 纠正」；**不调用** LLM。

## API

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/story/fragment_01` | 返回 `{ ok, graph }` |
| GET | `/api/stories` | 故事 id 列表 |
| POST | `/api/story/complete` | `{ story_id, player_name?, ending? }` |
| POST | `/api/story/reset` | 重开片段 01（测试/重温） |
| GET | `/api/lykie/state` | 含 `flags`、`story_pending` |

## 文件

- `data/stories/fragment_01.json` — 剧本
- `static/story.js` — runner
- `story/__init__.py` — 加载 JSON

## 姓名抽取

自报姓名（如「我叫李子峰」）会调用 `POST /api/lykie/extract_name`，只抽出名字本身再填入 `（玩家名字）` 占位符；未配置 API 时用规则剥离「我叫/我是」。

- 提示外输入的 LLM 意图分类 / 离谱拉回的模型版
- 合理偏离时的 LLM 填肉
- 交卷等待正式 2 分钟与可配置加速
- 交付答案与刷题题库联动校验
