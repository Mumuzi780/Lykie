# Lykie 第四版（V4.0）更新说明

> 面向用户与内测同学的版本说明。工程细节与按日摘要见 [`版本日志.md`](版本日志.md)；收纳规格见 [`交接-主仓-题库收纳重构.md`](交接-主仓-题库收纳重构.md) · [`交接-题库双栏侧栏重构.md`](交接-题库双栏侧栏重构.md)。  
> 发布日：2026-10-12

---

## 一句话

**这一版把「题库怎么收拾」做扎实了**：桌面与抽屉分离的双栏侧栏、全拖拽的归档与整理、跨端同步的排序；顺带学习通进题更稳、Lykie 换了新底子。

---

## 相对上一大版，你多了什么

### 题库收纳（本版重点）

1. **双栏侧栏**：左侧是文件夹导航（未分类 / 自己建的文件夹 / 归档），右侧只显示当前文件夹里的题库。点左栏切换，像项目与任务的关系。
2. **归档抽屉**：长期不用的题库拖进左栏「归档」；归档保留原文件夹归属，恢复时自动回到原位。归档题库不再出现在模考组卷、错题集、分享目标里。
3. **全拖拽整理**：
   - 右栏内上下拖 = 同级排序（拖起时变成小圆球，不挡视线，其余题库实时让位）；
   - 拖到左栏某文件夹 = 移入；拖到「归档」= 归档；拖回「未分类」= 移出；
   - 左栏文件夹本身也可拖拽排序。
4. **排序持久化**：所有排序存在账号数据里，换设备、刷新页面都保持；文件夹展开习惯不再依赖浏览器。
5. **移入文件夹统一走拖拽**：原「移入文件夹」弹窗已移除，菜单只剩分享 / 重命名 / 删除。
6. **学习痕迹**：题库条目记住最近学习时间（仅选中、答题时更新，导入、重命名不算），侧栏显示「N 天前」。

### 导入（学习通进题增强）

7. **纯文本规整**：学习通复制的纯文本自动规整——单选答案自动识别、多空填空按全角分号连接、题干剔除冗余信息；未匹配到学习通格式时原样返回。
8. **HTML 粘贴解析**：学习通页面直接粘贴（富文本）可解析单选 / 多选 / 判断 / 填空 / 简答五题型；解析失败自动回落纯文本管道，不影响原有流程。

### Lykie（换了底子）

9. **对话架构重构**：从多段式管道改为单次调用，规则层大幅精简，回复由档案事实驱动，更像她本人在说话。
10. **档案系统化**：人设档案重构为纯事实结构；新增作者工具 `/atlas`（条目化管理、分节权重、本地确定性散文生成与发布）。散文渲染零外部模型调用。

### 运行环境（工程侧）

11. 服务器迁移到裸 Ubuntu 26.04 LTS（systemd + Nginx，SSH 直连部署，弃用宝塔通道）；本地开发环境同步 Python 3.14.8，启动脚本重做。

---

## 使用建议（收纳）

- 建文件夹按「科目」建，章节题库拖进去；正在冲刺的科目留「未分类」桌面上。
- 拖拽时看左栏高亮确认目标再松手；拖到空白处松手 = 取消。
- 归档不是删除：模考不会带上归档库，想复习随时从「归档」拖回来。

---

## 本版明确不做（留到下一版及以后）

| 项 | 说明 |
|----|------|
| **自动归档 / 自动排序** | 收纳全部手动，不做「猜你想收」。 |
| **嵌套文件夹 / 标签** | 一层文件夹够用，层级越深越难找。 |
| **题库界面美化**（进度条 / 徽章 / 空态引导） | 候选清单已列，下一版按手感排期。 |
| 好友 / 关注 | 维持 V3 结论：分享不依赖好友图。 |
