# 简答训练 · 使用感受与后续调整方向

> 记录人：产品负责人实测反馈  
> 整理时间：2026-09-05 凌晨约 02:41（UTC+8）  
> 范围：短题子集「教资科二简答-短题」无脑训练流程（热身 → 特色阶段 → 答案选题干 → 无提示默写）

本文只记**实测结论与方向**，不锁定具体实现细节；实现随一题一题试感迭代。

---

## 1. 整体感受（前三阶段 vs 无提示）

- 经过前三个阶段若干轮练习后，**选择题式任务（热身 / 挖空或连线 / 答案选题干）已能做到秒选全对**。
- **无提示默写仍明显吃力**。
- 结论：前三阶段对建立熟悉度、降低进入成本**有效且明显**；问题不在「前三阶段没用」，而在于：
  - **从「选择/匹配」跳到「完全自己写」跨度偏大，中间不够连贯**；
  - 后续需要在「特色阶段」与「无提示」之间（或特色阶段内部）**加过渡手段**，具体措施待继续试感后再定。

### 1.1 「答案选题干」为何放在第三阶段（已验证有效）

- 热身多选时，用户会**很自然地只盯选项、不怎么看题干**（过眼要点即可过关）。
- 若不补一层「答案 ↔ 题干」联结，容易出现：要点眼熟了，考场却对不上是哪道题。
- 因此把**完整答案 → 二选一题干**放在第三阶段，是针对上述行为的刻意补强。
- **实测结论：这是一次成功的修改，应保留为默认流程中的固定环节**（干扰题干从题库原题抽，可同组）。

## 2. 分题体感对比（为何一道能默、一道不能）

### 2.1 「一堂好课的标准有哪些？」（连线题）

- 第二阶段做成**左右连线**后，练到的是「前半（目标/重点…）与后半（明确/突出…）的正确配对」。
- 无提示时**不再给出「前后」脚手架**，原先练熟的匹配能力**无法直接迁移成产出整句/整表**，因此默写卡壳。
- 方向：中间需要**额外阶段或变形练习**，把「配对能力」接到「无脚手架产出」上（例如先给一侧补另一侧、再逐步撤掉两侧提示等——具体形态待试）。
- 本题要点**多且碎**，框架不好抓，属于需要**重点强化**的类型。

### 2.2 「为什么说教学过程是一种特殊的认识活动？」

- 无提示下**已能较完整默写**。
- 有效原因归纳：
  1. 记住了清晰框架：**四个「认识的…」+ 一个「有指导的认识」**；
  2. 框架与内容能对上号；
  3. **框架本身好记**（逻辑简单、结构整齐）。
- 对比好课标准：不是「前三阶段无效」，而是**框架可记性差、点碎**，需要更强的强化与过渡设计。

### 2.3 对比带来的产品启示

| 题目类型 | 特征 | 无提示表现 | 启示 |
|----------|------|------------|------|
| 框架清晰、逻辑整齐 | 如「四性 + 有指导」 | 较易默出 | 热身 + 挖空 + 选题干往往够用，过渡可轻 |
| 点多、碎、靠配对 | 如「好课七条」连线 | 配对会了仍默不出 | 必须加强「配对 → 产出」过渡；重点强化 |

## 3. 当前阶段方案（备案用快照）

1. **热身**：离谱干扰多选，整点过眼。  
2. **题目特色阶段**（默认挖空；个别题连线等）：按题定制，一题一题试。  
   - **好课标准**：连线 → **半边挖空**（展示词尾、默词头；填不全给提示并换题交替，一次全对才晋级）。  
3. **答案选题干**：给出完整答案，二选一题干（干扰为题库原题干，可同组）。  
4. **无提示默写**：关键词命中作参考，用户决定是否完成本题。  

已知缺口：无提示仍可能吃力；半边挖空是否够用、是否还要「只默词头清单」等，继续试感。

## 4. 记忆曲线 / 复习抽取（最小实现 · 已落地）

- **学习车道**：未完成题仍两题一组走全流程；点「完成本题」→ `done`，`due_date = 明天`，`srs_level = 0`。
- **复习车道**：`due_date ≤ 今天` 的题轻测；**每批最多 2 道**，批满后须刷完一组学习题，再开下一批 2 道复习（无学习题时不卡批次）。
  1. **复习·默写**（过关 → 间隔 1→2→4→7→14 天）；
  2. 吃力可「先挖空复习」→ **复习·挖空/连线**（过关 → 明天再轻测，等级不升）；
  3. 挖空仍挂可「退回学习重练」→ 学习车道特色阶段。
- **状态栏**：`学习 n / 复习到期 n / 间隔中 n`。
- **旧进度**：已 `done` 且无 `due_date` 的题视为**今天到期**，方便回访立刻能复习。
- 未做：按题型分曲线、SM-2、会话疲劳限流（后续可加）。

## 5. 后续测试与调整流程（约定）

1. **一题一题感受**，不急着批量为全部短题定死统一模板。  
2. 对每一题找出**最贴合的特色解法**（例：好课标准 → 连线；其它题可能是无序挖空、只挖关键词、将来其它交互等）。  
3. 把验证有效的解法沉淀为**可复用工具/题型插件**（连线、无序挖空、…），以后同类题**直接套用**，而不是每题从零发明。  
4. 优先攻坚：
   - 「选择/匹配 → 无提示」的中间过渡；
   - **好课标准**这类多、碎、框架弱的题的强化路径；
   - **完成后再复习**（记忆曲线最小版已落地，见 §4）；碎点题强化与疲劳限流仍待试。  
5. 每轮试感结论继续追加到本文（修订记录写清**日期 + 凌晨/白天时刻**），避免只留在聊天上下文里。

## 7. 2026-09-05 下午补充体感（服务器测试前）

### 7.1 总评

- 产品**越来越成熟**；负责人实测下，**短时间已能记住好几道题**，说明当前漏斗（热身 → 特色 → 选题干 → 默写）主路径成立。
- **第一版可以上服务器做真实环境测试**；上线不等于功能封顶，下列缺口仍要排期。

### 7.2 记忆曲线（已做最小版）

- 见 §4：到期轻测 + 降级挖空 + 再挂回学习。  
- 服务器测试时重点看：回访是否还能抽到题、默写过载时降级是否好用。

### 7.3 「态度与品德」无提示：动脑过载

- 场景：流程走到**无提示默写**（说服 / 榜样 / 约定 / 角色 / 价值辨析 / 奖励与惩罚 六点）。
- 感受：
  - **分点零碎**，缺少好抓的总框架，和「好课七条」「点碎不好记」是同一类问题；
  - 前面已经刷过若干题，到这里**动脑量明显过大**，大脑有些**转不动**；
  - 不是「前三阶段无效」，而是**碎点清单 + 会话后半段疲劳**叠加，默写成本陡增。
- 启示（仍属方向，未定实现）：
  - 碎点题在默写前可能还要更强的骨架/过渡，或默写允许「先出骨架再填词」；
  - 会话长度与组题节奏也要考虑疲劳（不宜连续多道碎点默写硬刚）；
  - 与记忆曲线结合后，碎点题更适合「隔天轻测」而不是同一次会话里榨干。
