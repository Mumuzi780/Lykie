## 1. 产品原则（定稿）

1. **已知噪声系统处理**：如「一、单选题（20分）」「AI解析」等格式行，不进题干（`lykie/import_noise.py`）。
2. **偶发脏一点可接受**：结构大体对即可入库；刷到怪题当场编辑。
3. **截图不自研 OCR**：引导豆包等免费识字 → 粘贴回站；导入页提供洗稿提示词一键复制。
4. **站点不垫付**洗稿 / 识图账单；不承诺任意脏粘贴零瑕疵。
5. **答案认错是大忌**：标准模板为「答案：C」单独一行、「解析：…」另起一行；**不再**从括号抽解析，也不在解析长文里扫字母。非标准答案行标「待确认」，预览手选。
6. **题型不可静默漏掉**：滤噪声前扫描「一、填空题 / 判断题 / 简答题」等；未覆盖须补样板或显式确认跳过才能入库。
7. **简答不进客观库**：同次导入可另建 `mode=short_answer` 题库；刷题仍按题库隔离。

第一印象靠「能看到自己的题 + 预览大致对 + 流程像成品」，不靠无限修特例。

---

## 2. 用户主路径

1. 已有文字 / Word → `/import` 粘贴或抽 docx  
2. **题型检测**（总览）：只显示各题型题数与样板是否已选；点卡片进入该题型样板  
3. **单题型样板**：归并池在此页挑选；确认后回题型总览。可只选选择题再继续（将提示只导入已选类型）  
4. 预览校对（待确认答案置顶）→ 命名入库（可同时另建简答库）  
5. 开刷；怪题卡片「编辑」

## 3. 实现入口与流水线

```text
全文
  → import_scan.scan_pools  滤噪声前：题型 + 归并池（多节填空聚在一起）
  → import_noise            丢掉已知噪声行
  → import_exemplar         多样板 + 按大题分段切块
  → import_rules            单题块 → 可入库题
  → 预览 / 手选 / 题型门闩 → 客观库（+ 可选简答库）
```

约定：

1. **样板只切块**（结构听各题型样板）。  
2. **规则只成题**（内容听 `import_rules`）。  
3. **冲突时**：结构听样板，内容听规则。  
4. **门闩**：检测到判断 / 填空 / 简答但未覆盖 → 须 `ack_skipped_types` 或补样板 / 勾选另建简答库。

- 页：`/import`
- API：`/api/import_text`（`exemplars`、`ack_skipped_types`、`import_sa`）、`/api/import/scan`、`/api/import/extract`
- 扫描：`lykie/import_scan.py`
- 噪声 / 切块 / 成题：`import_noise` / `import_exemplar` / `import_rules`
- **脏文本样本库**：[`进题导入-脏文本样本.md`](进题导入-脏文本样本.md)
