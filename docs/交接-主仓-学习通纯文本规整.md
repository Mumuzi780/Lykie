## 要做什么 / 不要做什么

- 做：进题管道最前面加一个**纯规则**的"学习通格式规整"步，把学习通答题页复制出来的脏文本改写成现有流水线已支持的标准形态。
- **不要：调用任何模型**。零 AI，纯正则/状态机。
- 不要：改 `import_scan` / `import_noise` / `import_exemplar` / `import_rules` 的既有切块与成题逻辑（一处小改除外，见规格 C）。
- 不要：动答题/刷题逻辑、题库数据结构、简答通道。填空多空答案就是字符串，不改数据模型。
- 不要：做成通用平台框架。只收学习通这一种已知格式；以后新平台另立规整器。

## 现状锚点

- 进题入口：`app.py` 的 `/api/import/scan`（扫描）、`/api/import_text`（粘贴文本导入）、`_resolve_import_questions`（样板解析）。docx 走 `/api/import`。
- 切块逻辑：见答案行就收块（`import_exemplar._split_blocks_with_analysis`，`end_on_answer=True`）。
- 成题：`import_rules.shape_choice_block` / `shape_non_choice_block`；标准答案行只认 `答案：C` 单独字母，非标准 → `needs_answer_confirm`。
- 填空成题：答案须短文本且在答案行内；答案行 rest 为空 → 整题丢弃。

## 问题（已确认的脏法，样本见文末）

学习通答题页复制的文本特征：

1. 选择题答案行：`我的答案:A:内容;正确答案:A:内容;;`（一行内两个答案，字母后粘着内容）→ 现在全部落入手选。
2. 填空题答案在答案行**之后**：`正确答案：` 独占一行，随后 `(1) 答 (2) 答` 分块 → 现在块被「我的答案：」提前切断，答案段掉进下一题题干，填空整题丢失。
3. 噪声行未滤：`2.1分`（小数分值）、`AI讲解`。
4. 题号后粘连题型微标：`1. (单选题)`、`14. (单选题)某进程…将(` → 微标混进题干。
5. 大题标题本身可被现有扫描识别（`一. 单选题（共36题，78分）`），不用动。

## 规格 A · 新模块 `lykie/import_platform.py`

两个对外函数：

```python
def looks_like_xuexitong(text: str) -> bool
def normalize_if_known(text: str) -> tuple[str, str | None]
    """命中已知平台 → (规整后文本, 平台名)；否则 → (原文, None)。"""
```

检测条件（学习通）：文本含 `正确答案` 且含 `我的答案` 或 `AI讲解`。

规整规则（按行状态机，顺序执行）：

1. **选择/判断答案行**：行内含 `正确答案` →
   - 匹配 `正确答案\s*[:：]\s*([A-H]{1,6})\s*[:：.、．]` → 整行替换为 `答案：{字母}`。
   - 否则匹配 `正确答案\s*[:：]\s*(对|错|正确|错误|√|×)` → 整行替换为 `答案：对|错`。
2. **填空答案块**：行整行是 `我的答案\s*[:：]` → 进入跳过态，丢弃直到 `正确答案\s*[:：]\s*$` 的所有行；随后收集 `(k)` / `（k）` 编号的答案块（编号独占一行，答案文本在其后非空行；一空可多行），直到终结条件 → 输出单行 `答案：答1；答2；…`。
   - 空与空之间用**全角** `；`；一空内部的备选写法保留原文的**半角** `;`（如 `执行;运行`）。
   - 终结条件：题号行 / 大题标题 / 题型微标行 / `AI讲解` / `我的答案` / 文件尾。
3. **噪声行丢弃**：`AI讲解`；`^\d+\.\d+\s*分\s*$`（小数分值）；不含 `正确答案` 的 `我的答案…` 行。
4. **微标剥离**：`^(\d+)[.、．]\s*[（(](单选题|多选题|判断题|填空题|简答题|选择题)[)）]\s*(.*)$` → 重写为 `{N}. {rest}`（rest 可空）。
5. 其余行原样保留，包括大题标题行。

未命中检测时函数必须原样返回，**零副作用**。

## 规格 B · 接入点（`app.py`）

- `/api/import/scan` 与 `/api/import_text`：拿到文本后第一件事 `text, platform = normalize_if_known(text)`，下游扫描/切块/成题全用规整后文本。
- `/api/import`（docx）：同样过一遍 `normalize_if_known`；未命中零成本。
- 响应的 meta 里加 `platform` 字段（命中时为 `"xuexitong"`），前端可用来提示「已按学习通格式规整」；提示文案不做硬性要求，可后补。

## 规格 C · 既有代码唯一允许的小改

若 `import_rules` 中题号后粘连微标仍有残留场景（规整器漏网的），可在 `shape_choice_block`/`shape_non_choice_block` 取 stem 前剥掉 `^(单选题)…` 前缀。**优先在规整器做，这里能不改就不改。**

## 规格 D · 回归样本

- 新增 `tests/fixtures/import/dirty_xuexitong_001.txt`：用用户提供的真实样本（36 单选 + 10 填空，可裁到各 5 题但保留多空题与 `14.` 粘连微标题）。
- 在 [`进题导入-脏文本样本.md`](进题导入-脏文本样本.md) 登记：噪声点、预期题数、建议样板。
- 既有 fixtures（dirty_choice_001/002、dirty_mixed_001、dirty_chapter_heading_001）行为不变；特别是 002 的「答案：选C,因为…不猜字母」必须保留。
