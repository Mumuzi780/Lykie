# 顾问：自己写思考词表时要注意什么

> 给你看的。你可以自己写；当前不够准就改。试验台和正式站衔接上有一处限制。  
> 日期：2026-09-23

---

## 可以自己写

思考词表是作者工具，不是模型神秘内部。试验台左侧「思考步」那一层的正文，就是你在教思考模型：**有哪些格、每格何时用**。觉得不准，直接改那里试。

正式站里还有一份开口译句（程序里的 `ACTION_LINES`）：思考选出的标签，会变成拼进开口的那句「本轮动作：…」。词表要两端对齐，才不会「想的是 A、嘴被按成 B」。

---

## 试验台上的硬限制（改文案时要知道）

试验台当前逻辑是：

- 思考若输出 **不在** 程序白名单里的 `action`，会被 **改成 `thin`**；  
- 白名单现有：`thin` / `schedule` / `teach` / `deflect` / `push` / `silence`；  
- 开口译句也用这一份，不读你在思考层里写的中文解释。

因此：

| 你在思考层怎么写 | 实际效果 |
|------------------|----------|
| 仍用上述英文键，但改「何时选 push / thin」 | **立刻生效**（推荐先这样试） |
| 自创 `chat` / `ok` / `normal` 等新键 | 会被打成 `thin`，开口也按薄回——**除非**主仓扩白名单并加译句 |

先把现有键的**选用规则**写准，往往比发明新键更重要。真要新键，再交接主仓改试验台：允许自定义 action，或层内自带「标签 → 开口译句」。

---

## 自己写时的标准（避免再变语气旋钮）

1. **格 = 行为，不是语气。** 写「何时可以讲题 / 何时先不回」，少写「要怼、要傲娇」。  
2. **每格写清触发与禁止。** 例如：`push` 仅羞辱、连问审讯；打招呼问名 → 禁止 `push`。  
3. **必须有「正常接话」的格。** 现有六键里最接近的是 `thin`（偏少说）或将来的新键；不要让正常寒暄只能选 `push`。在改文案阶段，可暂时规定：寒暄、报名字 → `thin`，并写明 thin 可以短答+自然反问，不等于冷漠。  
4. **开口译句保持许可口吻。** 「可以短答、可反问」可以；「请顶回去、查户口」不要。译句在程序里，试验台改思考文案改不了译句——若 `push` 的译句仍是「顶回去」，即使你少选 `push`，一旦选中仍会冲。  
5. **不要越写越细。** 5～8 个行为格封顶；细节放在「何时选谁」，不要为每种口气加键。

---

## 建议你怎么试

1. 只改思考层：收窄 `push`、规定问名走 `thin`，`thin` 允许正常接话。  
2. 同一句「你好，你叫什么名字」连测几次，看还会不会稳定 `push`。  
3. 若仍冲：多半是偶发选了 `push`，开口译句仍在指挥——记下，再决定要不要让主仓改 `ACTION_LINES["push"]` 或加 `chat` 键。

---

## 一句话

词表规则你完全可以自己写；试验台先改「何时选哪个现有键」。自创键名目前会被打成薄回。写的时候管行为、管触发，别管音色；`push` 的开口译句仍偏「顶」，要连那一层一起才算改干净。
