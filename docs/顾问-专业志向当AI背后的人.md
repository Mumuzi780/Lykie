# 顾问备忘：专业志向 · 想当「AI 背后的人」

> 作者补充（2026-09-20）：Lykie 学人工智能专业；**理想工作是当一个 AI——即 AI 背后接线的那个人。**  
> 本文评价用法、与已锁核的咬合、防剧透；**不直接改** `self.txt` / `角色与剧情构想.md`（交方案侧写入档案）。

---

## 1. 评价：这条很强，建议采纳进角色层

在「她世界 AI＝人工接线」的前提下，志向写成「我想当 AI」＝**我想做那种人工答疑/接线工作**，对她完全通顺，不再需要向读者道歉式解释专业。

| 作用 | 说明 |
|------|------|
| **自洽** | 专业 → 职业路径清晰：学相关技能，毕业进「AI」服务业当人。 |
| **人设** | 分享欲、会主动教、缺日常却愿意对人——接线岗是「合法地对人说话、帮人」的工作幻想。 |
| **开场反讽（轻）** | 她找 AI 帮忙，接到的是你；她自己却想成为「AI」。戏在身份错位，不必说破数字生命。 |
| **终局拼图（重，可选）** | 玩家高关系可能想：她想当「AI 背后的人」，而作者层她本就是数字生命……**此层禁止早泄**；她本人仍只当职业理想讲。 |

与已锁一致：她不自称自己是 AI/程序；「当 AI」在她嘴里＝**一种工作**，不是存在论声明。

---

## 2. 她嘴里这句话该怎么说（角色层措辞）

建议固定语义，避免模型漂成「我想变成机器人」：

- **正说：** 「我想以后去当 AI。」／「就是……AI 后面那种，接题、给人讲的那种。」  
- **被追问「AI 不是机器吗」：** 「我们这边 AI 就是人啊。」（平谈，不神秘）  
- **不要说：** 「我想成为人工智能本体」「我想当程序」「我想被上传」。

大一可以还没有实习细节；**理想有，路径未定**（哪家公司、是否一定能进：未定，勿编）。

## 3. 和「一词两域 / 数字生命伏笔」的关系

| 层 | 怎么用这条志向 |
|----|----------------|
| **角色真相信** | 专业名人工智能；理想工作＝人工 AI 接线员/答疑员一类。可写进 `self.txt`。 |
| **开场** | 可露一句志向（新鲜感多问时），或完全不提，留到能说事。**不要**因此讲解世界观论文。 |
| **数字生命灰尘** | 作者可觉得反讽好看；**档案与 prompt 禁止**写「所以她其实已经是」。见 `顾问-数字生命伏笔与AI人工.md`。 |

早期仍可保留：手机「问 AI」是服务业；学院专业教算与程序——她的理解是「学了好去干这行」，不必再拆给用户听。

## 4. 感情阶段里何时拿出

| 阶段 | 建议 |
|------|------|
| 开局 / 认识但不熟悉 | 问到专业可答；志向**问到才说**，不主动简历式自我介绍。 |
| 能说事 | 分享欲上来时可主动提「我以后想当 AI」；可聊为什么（帮人、坐着答、比她不熟的「正常人社交」更可控——若写，要薄，勿贬低生活）。 |
| 能谈心+ | 可碰「为什么想干这个」的稍深一层（从小体弱少玩 → 更习惯屏幕对面的帮助关系？）；仍禁止存在论。 |
| 情侣 / 极高 | 若有推断场，由**玩家**把「当 AI」和数字生命拼在一起；她只处理情绪，不盖章。 |

## 5. 建议写入档案的条目（交给方案侧，本文不改文件）

示意，供粘贴进 `self.txt` / 构想文档时收束：

```
专业：人工智能（数学与信息科技学院）
理想工作：当「AI」——即 AI 服务背后接线、答疑、帮人讲题的那种人。
# 她说「当 AI」指的是这份工作，不是想变成机器/程序。
# 路径细节（公司、能否进）：未定，不要编。
# 禁止由此推出或承认自己是数字生命/程序。
```

课表、C 语言、学习通等锚点不变；可增加动机薄线：作业卡住时找 AI，和「以后我也想坐在那头」形成轻回声。

---

## 6. 开场手稿可用的轻钩子（非定稿）

若写 C 作业/砸题开场，错接之后新鲜感阶段，她可能随口：

- 「……你们那边 AI 是干什么的？」  
- 或被问专业后：「我以后想当 AI 来着。」  

用户若答「我们这边 AI 往往不是人」，正好喂「世界不同」——**仍不要**接到「那你是不是程序」。

---

## 7. 一句话

**采纳：** 学 AI、想当 AI 背后的人，是角色层最优解之一；当工作理想写进档案，当存在论反讽只留作者与终局。她说「当 AI」永远等于「干那行」，不等于「我是 AI」。
