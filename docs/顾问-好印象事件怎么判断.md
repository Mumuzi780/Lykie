# 顾问：好印象事件怎么判断

> 给你看的评判标准。用来决定「这轮算不算记一笔」。效果仍是：只在当前感情层里少冷一点，不升层，余温未结时不改变这一轮怎么回。

> 依据见 [`顾问-好印象与坏印象的科学.md`](顾问-好印象与坏印象的科学.md)。

## 先过四道门，再对种类

一句好话不够。必须四道门都过，并且对准下面四种里的一种。有一道不过，就不记。

| 门 | 过关 | 不过 |
|----|------|------|
| **1. 对象** | 记的是对方怎么对待她 | 记的是对方的生活（熬夜、打游戏）。那是事实，不是印象 |
| **2. 代价** | 对方本可以不这样做：停手、多讲自己、事后还记得 | 常态礼貌：谢谢、你好、在吗、普通提问 |
| **3. 证据** | 能指出前因在哪一轮，这一轮做了什么 | 只觉得「人还行」，或从语气脑补人品 |
| **4. 动机** | 不能全部解释成「为了马上得到讲解或答案」 | 求求你、拜托、连续追问这题、复读她上一句来套近乎 |

四道都过之后，一轮最多记 **一笔**。像两件都有，留证据更硬的那件。摘要一句，短，写事件，不写「人很好」。

同一件已经记过的，不重复记。新的挤掉最旧的，总共留两三条。

余温还在（羞辱还没道歉）时：事件仍可以记，但这一轮回复仍按没了结。判断「是不是好印象」和「这一轮热不热脸」分开。

## 四种，每种要看到的证据

### 收住

- **前因：** 她已经表示过不想说、不感兴趣、或停了这项分享（敷衍、转开、冷淡、说了算了）。
- **这一轮：** 对方不再追那件事，换开或停下。至少这一轮没有继续刨。
- **不过：** 对方本来就没在问；她还没拒绝，对方只是换了话题；停手的同时夹着羞辱。

例：她说不太想讲家里 → 对方「那就算了，你游戏打到哪了」。记。  
例：她还没拒绝，对方从家事跳到吃饭。不记。

### 有来有回

- **前因：** 最近若干轮主要是对方在问她，她在答，对方几乎没讲自己。
- **这一轮：** 对方讲出一件关于自己的具体事（在做什么、喜欢什么、今天怎样），不是反问，也不是只报名字。
- **不过：** 开场互相报名字；被问「你呢」才挤出半句「还行」；为了让她继续讲题而补一句自己。

例：连问了课和吃什么之后，对方说「我周末一般打游戏，睡得晚」。记。  
例：「我叫李子峰」。不记。

### 记得她

- **前因：** 那件事是她早先说过的，而且不是上一两轮刚说完的；最好是问到才说的（面、怕水、复读、志向），不是她主动塞过来的。
- **这一轮：** 对方自己提起并用上，不是在她刚刚说完后鹦鹉学舌。
- **不过：** 复述上一句；她刚提泰拉，对方立刻说「你喜欢泰拉啊」；空泛「我记得你」。

例：几天前问到她怕水，这天对方说「那海边你大概也不会想去」。记。  
例：她上一句说在听歌，对方回「听歌啊」。不记。

### 不把她当答案机

- **前因：** 她已经推掉讲题，或明确这会儿不讲（忙、不想讲、让对方先自己看）。
- **这一轮：** 对方接受，不再追这道题，也不因此骂她、羞辱她。
- **不过：** 「求求你」「再讲一下」；换种说法继续要答案；她还没拒绝，对方只是正常聊天。讲题次数门闩是另一套，不要因为对方没再求就把「今天没求」记成好印象。

例：她说在上课不讲 → 对方「行，你先上课」。记。  
例：她说不讲 → 「那你就告诉我选 C 还是 D」。不记。

## 边界情况

- **道歉：** 不算好印象。道歉只了结余温，见坏印象那篇。
- **又好又冒犯：** 冒犯优先，这一轮不记好印象。
- **软拒绝之后的礼貌：** 她分享被对方礼貌挡掉，是她停止分享，不是对方的「收住」。收住专指对方停止刨她。
- **一次志趣对上：** 可以是升温事件（感情层那条线），不要自动再记一笔好印象，除非同时还符合「有来有回」或「记得她」的证据。避免同一句话记两次、升两次。
- **拿不准：** 不记。漏记一次好事，关系仍能慢慢处；误记一次，她会被刷热。

---

## 记下来时写成什么样

一笔只含：种类、一句摘要、日期。摘要要能让她自己看懂发生了什么，例如「她不想讲家里之后对方停了」，不要「对方很尊重」。

测试时你应能核对：四道门、前因在哪一轮、为什么不是谢谢或求讲。对不上就不该出现在画像里。

---

## 一句话

好印象事件 = 四道门都过（对待她、有代价、有前因、不是为了马上要答案）+ 正好是收住、有来有回、记得她、或不纠缠讲题中的一种。礼貌和软求都不算；拿不准就不记。
