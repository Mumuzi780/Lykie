# 交接规格：题库双栏侧栏重构

## 背景

现行单栏侧栏中文件夹（含子题库）与独立题库在同一纵向滚动流。文件夹题库多时占满纵向空间，把题库拖入文件夹几乎没有可视目标区。重构为**双栏模型**：左栏=文件夹导航（项目），右栏=当前文件夹的题库列表（任务），与 Trae 的项目/任务关系一致。

本规格为定稿交互方案，替代《交接-题库文件夹层级系统重构.md》中的"文件夹展开/收起 + 归档抽屉"交互模型。数据模型沿用该文档已落地的 `sort_order` / `folder_id` / `archived` 三字段，无新增字段。

## 交互模型

### 左栏（文件夹导航）

```
📚 未分类          ← 预设，固定第一位
📁 操作系统
📁 教资
（+ 新建文件夹）    ← 左栏底部入口
🗄 归档            ← 预设，固定最后一位
```

- **预设项**：「未分类」= folder_id 为空的活跃题库；「归档」= archived=true 的题库。预设项固定首尾、不可拖拽、不可删除、不可重命名。
- **用户文件夹**：可创建、重命名、删除；在预设项之间按 `sort_order` 拖拽排序。
- **无展开/收起概念**：点选=切换右栏上下文。`collapsed` 字段废弃（数据保留，代码不再读写；`/api/folders/toggle` 后端保留不删，前端不再调用）。
- **选中态**：高亮当前项，存 localStorage（key: `lykieCurrentFolder`，值 `uncategorized` / `archive` / folderId），刷新恢复；无记录时默认 `uncategorized`。
- **操作按钮**：左栏窄（约 140px），文件夹项 hover 时显示 ✏️ / 🗑 迷你按钮；重命名/删除逻辑沿用现有 `renameFolder` / `deleteFolder`。
- **左栏项显示**：文件夹名 + 题库数徽章（含归档与否的活跃题库数）。

### 右栏（题库列表）

- 顶部显示当前文件夹名（上下文标题）。
- 只渲染当前上下文的题库：「未分类」→ 根区活跃题库；用户文件夹 → 该 folder_id 的活跃题库；「归档」→ 归档题库。
- 题库卡片操作沿用现状：未分类/文件夹视图有 查看/归档/更多（分享/重命名/删除）；归档视图有 恢复/删除。
- **模考合集**：固定显示于右栏列表末尾「模考」分区，不随文件夹过滤（全局入口），不参与拖拽排序。
- **新建题库/导入入口**：位置不变（侧栏头部），行为见下。

### 拖拽矩阵（复用现有几何命中引擎 `movePlaceholderNear`）

| 源 | 目标 | 行为 |
|----|------|------|
| 右栏题库 | 右栏同上下文内 | 排序（现有逻辑，容器=右栏列表） |
| 右栏题库 | 左栏用户文件夹 | 移入该文件夹，追加末尾 |
| 右栏题库 | 左栏「未分类」 | 移到根区，追加末尾 |
| 右栏题库 | 左栏「归档」 | 归档 |
| 归档视图题库 | 左栏任意文件夹/未分类 | 恢复 + 移入 |
| 左栏用户文件夹 | 左栏内其他位置 | 文件夹排序（sort_order 持久化） |
| 预设项（未分类/归档） | — | 不可拖拽（不绑 mousedown） |

拖拽视觉：拖动题库悬停左栏文件夹时该项高亮（复用 `.drop-hover`）；占位符仍只在右栏内显示排序位置，悬停左栏时右栏占位符隐藏。

### 导入与新建题库归属

- 导入成功后：当前上下文为用户文件夹 → 前端对新 bank id 追加一次 `/api/banks/move`；当前上下文为「未分类」或「归档」→ 不调 move（归档视图导入进未分类）。
- 导入 API 本身不改（不加 folder_id 参数）。
- `ensure_sort_defaults` 会为新 bank 在分组内补末尾 sort_order，追加末尾行为天然正确，无需额外处理。

## 后端改动

**无新 API，无数据模型变更。** 复用现有接口：

- `/api/banks`（GET）：已返回 sort_order + folders（含 sort_order/collapsed）
- `/api/banks/move` / `/api/banks/reorder` / `/api/folders/reorder`
- `/api/banks/archive` / `/api/banks/unarchive`

`/api/folders/toggle` 前端停止调用，路由保留。

## 边界处理

- **删除文件夹**：子题库 folder_id 置 null 退回未分类（现有逻辑），若删除的是当前选中文件夹 → 自动切回「未分类」。
- **空文件夹**：左栏正常显示（数徽 0），右栏显示空态提示"拖入题库或导入"。
- **旧数据**：无 sort_order 的 bank/folder 由 `ensure_sort_defaults` 兜底（已上线，不动）。
- **移动端**：本轮不做。现有媒体查询下侧栏若挤爆，最小处理：窄屏时左栏降级为横向滚动 chips 条（可作为验收外的宽松项，实现者自行判断工作量；超出则记录 TODO 留下轮）。

## 验收标准

1. 左栏：未分类/用户文件夹/归档 + 新建入口；点选切换右栏；选中态刷新保持
2. 右栏只显示当前上下文题库；模考合集固定在右栏末尾可见
3. 拖题库到左栏文件夹=移入、到归档=归档；归档视图拖出=恢复+移入；全部落库刷新保持
4. 右栏内题库排序、左栏文件夹排序均持久化，无闪烁（沿用几何引擎）
5. 新建/重命名/删除文件夹正常；删除后子题库回未分类、视图自动切回
6. 导入题库进当前选中的用户文件夹（未分类/归档视图导入进未分类）
7. 回归：模考组卷勾选、错题集、分享目标自动过滤归档题库不变；选中题库切栏不丢失
8. 旧账号数据（无 sort_order / collapsed 缺失）加载无异常

## 注意事项

- 拖拽一律走自定义鼠标拖拽引擎，禁止恢复原生 HTML5 DnD（dragover 读不到 dataTransfer 的坑已知）
- 文件夹拖拽与题库拖拽共用 `movePlaceholderNear`，但两场拖拽的占位符/容器不同，注意状态变量分离，防止互相污染
- `currentBankId` 与 `currentFolderId` 是两个独立状态：切换文件夹不清空选中题库；选中题库所在文件夹被删除时，题库仍在未分类可见
