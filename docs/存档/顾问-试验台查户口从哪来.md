# 顾问：试验台里「查户口」从哪来

> 给你看的。对照你干净试验台那一轮：人格很短、无口吻层，却回成「一上来就查户口」。  
> 日期：2026-09-23

---

## 结论

不是漏加的语气规则，也不是正式站的记忆/监督串进来了。  
影响她的主要是：**思考步的动作词表太粗，加上程序把 `push` 译成「顶回去」写进开口。**

因果链：

1. 思考步只能选 `thin | push | silence`。没有「正常熟人寒暄」之类。  
2. 「你好，你叫什么名字」被想成要反问、抢话头 → 词表里最像的是 `push`。  
3. `why` 其实写的是「可以正常回应并顺势反问」——意图偏正常，标签却选了冲的那一格。  
4. 开口前程序追加正式站同一句：`本轮动作：push。顶回去或扣住……`  
5. 开口模型按「顶」来演 → 「查户口」「你谁啊」。  
6. 人格只有「女大学生」：挡不住这种演法，有时还会借中文网感里的「问名字＝查户口」梗。

所以你看见的冲，是 **动作标签在指挥语气**，不是人格层写了要凶。

---

## 试验台里到底有什么规则

| 来源 | 这轮有没有 | 作用 |
|------|------------|------|
| 你勾的人格 | 有，很短 | 只定身份，不定冷热 |
| 开场情境 | 未勾 | 无 |
| 口吻皮 / 正式监督 / 画像 | 试验台设计为隔离，这轮也没勾 | 无 |
| 思考步提示里的 `push=顶或扣住` | 有 | 教思考怎么分类 |
| `lykie/llm.py` 里 `ACTION_LINES["push"]` | 思考开启后自动拼进开口系统提示 | **直接规定这轮要顶** |
| 模型预训练习惯 | 有 | 「问名字」易联想到查户口玩笑 |

系统栏显示「写入系统 19 字」只统计你勾的 system 层；**思考选中的动作句是另拼上去的**，容易让人以为开口几乎无约束。

---

## 这说明什么

思考步不是中性开关。  
**动作名字 + 开口译句 = 隐形语气规则。**  
词表只有 thin/push/silence 时，很多「正常但想接住/反问」的回合会被硬塞进 `push`，然后开口必冲。

`why` 和 `action` 还可以不一致：理由写正常，动作写顶——开口只听动作，不听理由。

---

## 试验时可以怎么验

1. **关掉思考步**，同一句「你好，你叫什么名字」再发一次。若明显不那么冲，就坐实是 `push` 链路。  
2. 思考仍开，但暂时改词表：加一个 `chat`/`ok`＝正常接话，并给对应的开口译句（不是「顶」）。看还会不会动不动 `push`。  
3. 或收窄 `push`：只用于羞辱、连问审讯、冒犯；寒暄问名禁止选 `push`。  

这些是试验设计，不是让你现在改正式站。正式站里 `push` 本意是冒犯时用的；试验台词表过粗时，会把寒暄误判进同一格。

---

## 一句话

没有口吻层也会冲，因为 **`push` 本身就是一条很重的语气指令**；这轮是思考误把打招呼问名放进 `push`，开口再按「顶回去」演出来的。
