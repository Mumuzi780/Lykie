# 顾问：成熟产品怎样把大模型「包」成想要的样子

> 给你看的行业对照。回答：类似产品一般怎么做；你们现在的拆法落在哪一层；别再靠堆规则硬拧。  
> 日期：2026-09-23

---

## 先降低一个幻觉

没有成熟产品是靠「把性格说明书写到两万字」就把模型变成固定的人。  
能稳定像某个人的，几乎都是 **好几层一起包**：模型本身的习惯、短核、按需记忆、有时还有第二步判断或事后过滤。提示词只是外壳的一层。

你碰到的「规则 ↔ 思考」矛盾，行业里同样存在；常见解法是**少写禁令、多拆步骤、多用检索、必要时改权重**，而不是写更长的宪法。

---

## 常见包装栈（由内到外）

### 1. 权重里的「会扮演」

平台级角色站（如 Character.AI 一类公开技术叙述）会做 **角色向的后训练**：不是只训某一个角色，而是训「读到一段人设就进入角色」的能力。性格写成「我是……」这类宪法句，再生成偏好对去做对齐。  
效果：角色感一部分进了模型习惯，提示词可以更短。

独立游戏、小站通常 **买不到这一层**（自训贵）。你们用通用 API，等于跳过这一层，所以更依赖后面几层——这正常，不是你落后。

### 2. 短核（Constitution / 人设卡）

几乎所有产品都有一份 **短、硬、少改** 的人设：名字、说话质感、绝不能做的几件事。  
成熟做法是：核保持短；上下文溢出时 **优先保留人设，裁对话**（有的内部工具甚至按模板优先级截断）。

反模式：把每一次点踩都写进核。那是判例汇编，不是人设。

### 3. 对话短期记忆

最近 N 轮原文。人人都有。只解决「刚才在说什么」，不解决「三个月前怎样」。

### 4. 长期记忆：先压缩，再按需取

研究与角色系统里很常见的一条：原始长文进提示词会污染注意力。流程是：

- 互动 → 抽成短记忆（关于自己 / 关于对方 / 事件）；  
- 回复前 **检索相关几条** 再生成；  
- 有的还加遗忘或衰减，避免旧事永远同权重。

评价上会强调：回复要 **落在取到的记忆上**，而不是模型现编。  
这和你们「档案按需查、禁止现编」是同一哲学；差别是成熟产品往往把「用户事实 / 关系事件」也做成可检索库，而不是每轮全塞。

### 5. 人设与行动拆开（Agent 向）

较新的个性化 Agent 框架会拆：

- **记忆**（情景事件 vs 稳定特质）；  
- **行动**（检索、工具、是否开口）；  
- 中间用一份 **persona / 本轮策略** 当胶水。

「先决定再说话」属于这一族。你们的思考步 + 开口步，已经踩在成熟方向上，不是野路子。

### 6. 示例，而不是禁令海

社区角色卡（酒馆一类）、以及平台上的好角色，大量靠 **少量高质量对话样例** 定音色。  
样例教的是「像什么」，禁令教的是「别像什么」。禁令多了就进入合规模式——正是你现在的痛。

监督案例若当「每轮全文判例」用，会退化成禁令海；若当「这一问法相近时取一条」用，才接近样例检索。

### 7. 生成后的闸门（可选）

安全、泄核、自称 AI、超长列表：有的产品用 **分类器 / 正则 / 二次改写** 挡在用户眼前。  
闸门管的是硬违规，不是管「这层该不该冷」。冷热仍应在决定步，否则又变成开口时两边讨好。

### 8. 产品层的「不是纯聊天」

彼方的她、生命线一类：大量节拍是 **手写剧本 + 等待**，模型只填局部或根本不填开场。  
角色感有一半来自 **何时出现、说不说、等不等**，不是来自更聪明的一句回复。  
你们：开场手写、可以沉默、题要她交给才看见——都是这一层，值得保住。

## 对照：成熟做法 vs 容易翻车的做法

| 成熟一点的 | 容易翻车的 |
|------------|------------|
| 核短；细节进记忆库 | 核越写越长 |
| 态度用状态机 / 决策步 | 态度写进几十条口吻 |
| 记忆检索几条 | 每轮全文档案 + 全文监督 |
| 样例少而精 | 点踩自动变全局永久规则 |
| 冲突时删旧规则 | 再加「除非」仲裁第三条 |
| 剧本管第一夜与节点 | 指望模型自己演出完整开场 |

## 和你们现状的位置

已经对齐的：

- 思考 / 开口拆开；  
- 开口短核；  
- 材料按需；  
- 感情层当许可；  
- 开场可手写；可沉默。

仍偏「小作坊复发」的：

- 全站口吻 / 监督易堆积，且曾与层、判断抢「必须遵守」；  
- 一出错就想加禁止句；  
- 用别的系统设计（画像科学）躲开开场与清理。

下一步若要对齐成熟产品， priority 通常是：

1. **减负**：口吻与监督降权、去重、别进每轮开口（你们开口路径已开始这样做）；  
2. **检索化**：监督与事实「相关才带」，不是「最近 N 条全带」；  
3. **核继续瘦**：判断句只留在思考；  
4. **手写开场**：产品层补上模型补不稳的第一夜；  
5. **自训角色模型**：很远、很贵，现在不必。

## 「包装成希望的样子」一句话流程

```
短核（她是谁）
  + 本轮状态（层、印象余温、忙闲）
  + 决策（想不想讲、顶不顶）
  + 检索到的几条记忆/样例
  + 最近几句对话
  → 生成
  → （可选）硬违规闸门
```

希望的样子 = **状态机 + 检索 + 短扮演**，不是 **更长的说明书**。

## 可读锚点（想深挖时）

- Character.AI 一类：角色后训练 + 人设提示优先级（公开技术评述，非官方白皮书）  
- 虚拟角色长期记忆：先浓缩再检索再生成（如 INLG「Memories for Virtual AI Characters」）  
- 超长对话记忆评测：LoCoMo 等——证明只靠长上下文不够  
- PersonaAgent 等：记忆与行动分离、persona 当中间层  

不必都读。对你够用的结论就在上面的栈和对照表。

## 一句话

成熟产品把模型包进「短核 + 状态 + 决策 + 按需记忆 +（可选）后训练/闸门」；禁令海是业余场的默认动作。你们缺的不是更多规则，而是把已拆开的包装栈守住、把堆积的口吻皮减掉，再用手写开场补产品层。
