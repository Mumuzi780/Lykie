## 规格 A · 每一轮先想再开口

闲聊一轮（含用户把题送进对话的那一轮）变为：

1. **思考**（模型，低温，约 0.2）：只出结构，不出台词。输入要短：最近几句、当前这轮用户内容、当前层许可、印象里有没有未道歉的冒犯、程序给出的忙/能聊、**这轮用户有没有把题面发进来**。不要附带整份 `prompt_core` 和整份档案。
2. **查**（程序 if，不用 function calling）：只取思考点名的材料。
3. **开口**（模型，口语温度保持现有）：短核 + 本轮 `action` + 查到的几条 + 最近对话。

思考原文**不写入** `chat_tail`。气泡和记录里只有开口。

### 思考字段

| 字段 | 含义 |
|------|------|
| `action` | `thin` 薄回 / `schedule` 按日程 / `teach` 讲题 / `deflect` 少说或停分享 / `push` 顶或扣住 / `silence` 先不回 |
| `need` | `none` / `timetable` / `question` / `profile`，宜少 |
| `profile_topics` | 点名档案块（课表、怕水、志向等），禁止「全部」 |
| `why` | 一两句，给人看 |
| 测试用 | 是否看见题面、愿不愿意、忙不忙、最终为何不是 `teach` |

想不好：`action=thin`，`need=none`。思考步不编她的一天。  
`silence`：可跳过开口，沿用现有沉默与直攻降层。

### 查什么

| need | 取什么 |
|------|--------|
| `timetable` | 档案课表中与「现在」有关的片段 + 现有当前时间 |
| `question` | **仅当这轮用户消息里带了题面**。肯讲（`teach`）才附参考答案/解析；不讲则开口步只有题面或明确「不要交付解析」 |
| `profile` | 只摘点名的块，不注入整份 `self.txt` |
| `none` | 开口步不带档案正文 |

查空：开口步被告知没有这条，含糊或不答，不现编。测试面板能看到查了什么、是空的。

一轮限制：一次思考、最多一两样资料、一次开口。记事实/印象/口吻仍在开口之后，不并进思考。

### 开口变瘦

- 留下短核：她是谁、不认程序、不嘴硬、按当前层冷热、短句、`[不回复]` 格式。
- 口吻纠正与监督案例不要每轮全文；第一版可先不带，或只带与这句最像的一条。
- `%%档案` 不再由开口模型输出。

### 思考给谁看

- 响应增加 `think`（`action`、`need`、`why`、查到了什么、两关结果）。
- 测试：面板在气泡旁显示。开关在服务端（环境变量或仅作者账号）。不带开关则响应里没有 `think`。
- 不要只靠前端藏字段。

### 建议实现顺序（Plan 可调整，但不要跳过「先只展示」）

1. 加上思考并显示；开口仍用现在的胖提示，思考**不驱动**开口。用来核对判断像不像。
2. 开口改为听 `action`，档案按 `need` 摘取；拿掉整份档案与整份监督。
3. `%%档案` 退出开口；缺档案的提示改绑查空。
4. 词汇库等更多工具不做。主动找用户说话不做，除非 Plan 里单列且作者另点头。

## 规格 B · 按钮改为「把题面交给对话」

取消「一点就讲解」的 `explain` 通道。提示词不得再写「用户点了问问 Lykie，请讲解」。

### 交互

- 题卡上的按钮：把**当前题的题面**挂到对话输入区，成为待发块（类似待发图片）。不写入系统剪贴板，不要求用户再粘贴文字。
- 按下**不发送**、不叫模型。
- 用户自己选时机送出：可单独发这块，或和一句「这题看一下」一起发。走现有「停手再回」的连发节奏，不要插进她尚未回复的生成过程里替用户抢发。
- 再点另一题：替换尚未发送的待发块。划掉待发 = 没发过。
- 按钮文案不要用「问问 Lykie」。用「交给她 / 放到对话里」一类。具体用词 Plan 里给一版，作者可改字。
- 开场手写剧本期间：不能把题送进模型（与现在禁用问问一致）。

### 她何时看见题

| 时刻 | 模型上下文 |
|------|------------|
| 正在刷题，没挂上或没送出 | 无这道题 |
| 待发还在输入区 | 无这道题 |
| 用户送出之后 | 有题面（题干、选项、必要的图或空） |
| 换了卡但没再送 | 只有聊天记录里已经送出过的题 |

聊天记录里存用户送出的题面，不存解析。她之后「记得这题」只因为记录里有，不是因为能翻题库。

### 肯不肯讲

不另做好感条。用现有感情层 + 印象：

| 条件 | 行为 |
|------|------|
| 认识但不熟悉 | 可以收到题面，不展开教。短、冷、让对方先自己看。 |
| 能说事及以上 | 可以 `teach`。主动讲仍少；常态是对方把题给了才讲。 |
| 未道歉的羞辱，或这轮仍在冲 | `push` 或 `deflect`，**不附解析**。 |
| 明确「你很烦 / 我不想听」 | 现有沉默与降层，不讲。 |

有没有空：程序按课表 + 当前钟点先标 `busy` / `free`，再交给思考。粗分即可（此刻在课或军训整段 → 忙；晚上写作业时段与很晚 → 在 `why` 里可被开口说成在写作业或困）。不要模型自编今晚行程。不要精确到「这节课还剩几分钟」，除非以后档案写了。

拒讲用她的话说明（在上课、自己也在写、不想讲），不要系统文案「当前不可用」。偶尔 `silence` 可以，不要随机经常不回。

问一次题、教一次题，都不因此改感情层。

刷题页的看答案、斩题与她是否回复无关。

## 验收（Plan 的方案应能对上）

- [ ] 普通闲聊一轮有思考调用；作者调试时面板能看到 `action` / `why`；无调试开关的响应不含思考；`chat_tail` 无思考原文。
- [ ] 思考尚未驱动开口时，回复行为与现在一致（第 1 步）。驱动之后，开口不再注入整份档案。
- [ ] 未把题送进对话时，模型上下文没有当前卡的题干和解析。
- [ ] 按钮只产生待发块；发送前换题、取消均不会让她「看过」。
- [ ] 送出的气泡只有题面，没有参考答案和解析。
- [ ] 生、被冒犯、或程序标忙时，可以不讲，且开口上下文不带解析。
- [ ] 层够、不忙、用户已把题送出时，可以讲；不会就支吾，不把解析当她不会时的硬编来源以外的泄底（不会则不念解析）。
- [ ] 错字沉默、直攻降层、开口后记事实/印象/口吻、开场不走模型，仍在。
- [ ] 不改人设档案文件。
