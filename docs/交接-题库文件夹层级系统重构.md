# 交接规格：题库文件夹层级系统重构

## 背景

当前题库侧栏的"文件夹"只是扁平标签，用户需要真正的层级收纳：
- **文件夹 = 科目**（如"操作系统"、"教资"）
- **题库 = 章节/子科目**（如"第一章"、"科一"）
- 文件夹可展开/收起，形成二级菜单
- 同级（同文件夹内、同根区、同归档区）可拖拽排序
- 跨层级拖拽 = 移动（改变 folder_id）

## 交互模型

```
📁 操作系统（3）          ← 文件夹头部，点击展开/收起
   ├── 第一章 [已斩 36/36]   ← 子题库，缩进显示
   ├── 第二章 [已斩 28/50]
   └── 第三章 [已斩 0/20]
📁 教资（2）
   ├── 科一 [已斩 10/30]
   └── 科二 [已斩 5/25]
📄 独立题库A [已斩 0/10]      ← 根区题库（无文件夹）
🗄 归档（8）                  ← 归档抽屉
   ├── 旧题库1 [已归档]
   └── 旧题库2 [已归档]
```

**规则**：
- 文件夹头部显示名称 + 子题库数量
- 文件夹可展开/收起，状态持久化到后端
- 同级内可拖拽排序（同文件夹、同根区、同归档区）
- 跨层级拖拽 = 移动（改变 folder_id）
- 文件夹本身可拖拽排序（根区同级）
- 归档题库只能恢复或删除，不能移动/排序

## 数据模型变更

### bank.json 新增字段

```json
{
  "banks": [
    {
      "id": "xxx",
      "name": "操作系统第一章",
      "folder_id": "folder_001",
      "sort_order": 0,
      "archived": false,
      "last_studied_at": "2026-10-12 00:02"
    }
  ],
  "folders": [
    {
      "id": "folder_001",
      "name": "操作系统",
      "sort_order": 0,
      "collapsed": false,
      "created_at": "2026-10-11 20:00"
    }
  ]
}
```

**字段说明**：
- `sort_order`：同级排序权重，数字越小越靠前。新增时自动追加到末尾（当前同级最大 sort_order + 1）
- `collapsed`：文件夹展开状态，默认 false（展开）
- `folder_id`：所属文件夹，null/"" 表示根区

**兼容性**：旧数据无 sort_order/collapsed 字段，加载时自动补默认值。

## 后端 API

### 1. 排序接口

```
POST /api/banks/reorder
Content-Type: application/json

{
  "type": "bank",
  "parent_id": "folder_001",
  "ordered_ids": ["id1", "id2", "id3"]
}
```

**参数**：
- `type`：`"bank"` 或 `"folder"`
- `parent_id`：父级 ID。`type=bank` 时为 folder_id（null/"" 表示根区），`type=folder` 时忽略
- `ordered_ids`：目标顺序的 ID 列表，未出现的保持相对顺序接在末尾

**响应**：
```json
{
  "ok": true,
  "banks": [...],
  "folders": [...]
}
```

### 2. 文件夹展开/收起

```
POST /api/folders/toggle
Content-Type: application/json

{
  "folder_id": "folder_001",
  "collapsed": true
}
```

**响应**：
```json
{
  "ok": true
}
```

### 3. 文件夹排序

```
POST /api/folders/reorder
Content-Type: application/json

{
  "ordered_ids": ["folder_001", "folder_002"]
}
```

**响应**：同 `/api/banks/reorder`

## 前端实现

### 渲染逻辑（renderBankList）

1. 从 `/api/banks` 获取 banks + folders
2. 按 sort_order 排序：folders 按自身 sort_order，banks 按 folder_id 分组后按 sort_order
3. 渲染顺序：folders（含子题库）→ 根区题库 → 归档抽屉
4. 文件夹子列表默认渲染，用 CSS `max-height` + `overflow: hidden` 实现折叠动画

### 拖拽逻辑

**同级排序**：
- 拖拽题库到同文件夹内另一个题库上 → 排序
- 拖拽题库到根区另一个题库上 → 排序
- 拖拽文件夹到另一个文件夹上 → 文件夹排序

**跨层级移动**：
- 拖拽题库到文件夹头部/子列表空白处 → 移入该文件夹（追加到末尾）
- 拖拽题库到根区空白处 → 移出文件夹（追加到根区末尾）
- 拖拽到归档抽屉 → 归档

**拖拽指示器**：
- 同级排序：目标元素上方/下方出现水平线
- 跨层级移动：目标文件夹/区域高亮边框

### 样式要求

- 文件夹头部：hover 背景色变化，cursor: pointer
- 子题库：padding-left: 24px（缩进）
- 归档抽屉：头部显示"🗄 归档 (N)"，默认折叠，但保留头部可见
- 拖拽中：半透明 + 虚线边框
- 拖拽目标：2px 实线边框（同级排序）或高亮背景（跨层级移动）

## 验收标准

1. 文件夹可展开/收起，状态保存到后端，刷新后保持
2. 同级题库可拖拽排序，顺序保存到后端，刷新后保持
3. 题库可拖入/拖出文件夹，folder_id 正确更新
4. 文件夹可拖拽排序，顺序保存到后端
5. 归档抽屉正常显示，归档题库只能恢复/删除
6. 模考/错题/分享自动过滤归档题库
7. 旧数据兼容：无 sort_order/collapsed 字段时自动补默认值
8. 所有操作有视觉反馈（hover、拖拽指示器）

## 注意事项

- 归档题库不参与排序（archived=true 的 banks 不响应 reorder）
- 删除文件夹时，子题库自动移回根区（folder_id 设为 null）
- 新增题库时，根据当前选中位置自动分配 folder_id 和 sort_order
- 拖拽排序使用 HTML5 Drag and Drop API，注意 dragover 阶段无法读取 dataTransfer 数据（需用全局状态变量）
