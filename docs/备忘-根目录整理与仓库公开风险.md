## 风险清单（按严重度）

### 1. env备份/env —— 危险
- 内容：`.env` 副本（120 字节，含 API Key）
- 问题：`.gitignore` 只忽略精确的 `.env` 路径，管不到 `env备份/env`
- 一次 `git add -A` 就会把它加进提交并推上 GitHub
- **建议：整份移出仓库目录**（密钥副本不应存在于 git 仓库内）；只加 ignore 是次选

### 2. 用户数据备份/ —— 隐私
- 内容：`users_WcP4T` 账号数据（含 Lykie 对话史等）
- 建议：移出仓库目录或加入 `.gitignore`

### 3. 四级真题/、教资题目素材/、组成原理原题文件/ —— 版权
- 内容：真题 PDF、老师原题 docx，均为第三方版权材料
- 若仓库将来公开（部署讨论中的备选项），公开仓库不应携带
- 建议：加入 `.gitignore`（个人学习素材不需要版本管理）

### 4. 杂项素材/ —— 低
- 内容：favicon 等图片副本、课表 docx；站点实际使用 `static/lykie/` 下的文件
- 建议：随其它素材一并 ignore
