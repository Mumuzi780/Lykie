# 顾问：抗拒写开场时怎么办

> 给你看的。你已经看清：一部分「乱」是用好坏印象躲开开场；开场缺、旧稿大改、要挤思路，所以累、所以拖。  
> 日期：2026-09-22

---

## 先把这件事说清楚

抗拒写开场，在这种产品里很常见。开场要同时扛：第一印象、世界不同、她是谁、你怎么进来。一次写砸，后面几天的聊天都泡在错的第一夜里。脑子会自动去找「好像也很重要、但不用面对第一夜」的题——画像、印象、科学，都是很好的逃避题。

看清这一点就够了。不必为此自责，也不必今晚用意志力硬写完整场。

旧稿整套作废的感觉会加重抗拒：那不是「少写一段」，是「已经付过的力气要再付一次」。正确的对照不是「从零发明」，而是「旧稿里哪些零件还能拆下来用」。

---

## 你真正在怕的几件事

| 怕 | 实际可以怎样 |
|----|----------------|
| 要一次写完美、和日期四皮全对齐 | 第一版只写**一皮**、一条误接骨架，其它皮以后贴 |
| 旧期末砸题整段作废 = 全弃 | 短句连发、抢话感、互报姓名、世界不同摊开——这些节奏可以留，换的是**第一问和为什么急** |
| 要挤出全新灵感 | 第一问从已定清单里**选**，不是现场发明大学生活 |
| 写完还要接程序 | 手稿先写成能念的对话；接 `fragment` 是下一步，不是今晚的事 |

---

## 把开场缩到「最小可写」

目标不是「新开场定稿」，是「有一场能播完、落在认识但不熟悉的手写夜」。

**只做这一皮（默认）：** 开始上课 · C 卡住或短课内题（你日历若在学期头，就改用校园卡/收手机那类规矩题，仍只写一皮）。

**共用骨头（写一次）：**

1. 她砸来第一问（短、脏、急）。  
2. 你回得不像人工接线。  
3. 她觉得不对 → 世界不同可以说开。  
4. 新鲜感里互问一点（含姓名）。  
5. 收束：下次再聊 → 认识但不熟悉。

**明确不做：** 四皮齐全、数字生命、志向演讲、好印象、完整课表演出、旧交卷死刑倒计时。

旧稿若还在：打开它，只圈「仍想要的节拍」（连发、打断、介绍），把第一问和「交卷」换成「今晚学习通 / 这题卡住」。大改变成换皮，比重写小说轻。

---

## 挤思路时用「选」不用「发明」

第一问从已有池子里勾一个：

- 学习通 C 报错或一小段过不了  
- 「这课算不算水课」  
- 校园卡 / 上课收不收手机（开学皮）

错解接口固定成一种就行：你像人一样追问、扯远、或露出她那边没有的常识 → 她说 AI 不对劲。

卡文时只写**气泡清单**，不写漂亮叙述：她一句、你选项两三个、她一句。一天写通 8～12 个气泡，比想「整场戏的文学性」容易动手。

---

## 和画像的关系

画像三篇继续冻。你不是「开场写完才能碰画像」，而是**开场有一场可播之前，不要用画像当主任务**。逃避的出口堵上，阻力会集中到开场上——这反而正常；用上面的缩小法接住它。

---

## 一句话

抗拒是因为开场太重、旧稿像白费。先只写一皮最小夜：旧节奏可拆、第一问从池子里选、今晚只追求能播完。画像先别碰。
