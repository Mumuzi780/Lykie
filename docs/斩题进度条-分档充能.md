# 斩题进度条：分档文案与充能

> 斩题进度条的体验备忘：四档短句、短暂渐显、闪电充能。  
> 与「多留下已经会了的证据」同向；条下数字是安静证据，跨档彩蛋是短暂情绪。

最后整理：2026-09-15

---

## 界面分工

| 位置 | 常驻 | 跨档彩蛋 |
|------|------|----------|
| 进度条上 | 仅「斩」字 | 分档短句：渐显约几秒后消失 |
| 进度条下 | `已斩 x / y`（或百分比）安静展示 | 不改成夸奖文案 |

夸奖**不常驻**条上，避免占位、抢刷题注意力。

---

## 四档文案（已定）

| 进度 | 文案 |
|------|------|
| **25%** | 还不错 |
| **50%** | 一半入袋了 |
| **75%** | 最后一公里，别绊倒 |
| **100%** | 全部拿下，休息一下再出发 |

递进大致是：短肯定 → 过半俏皮 → 收尾提醒 → 结算式收工（可再出发）。

---

## 触发与播放规则

1. **只在跨过某档时播一次**（例如 24%→26% 才播 25% 档），不要每次斩题都闪。  
2. **文案**：渐显，约 **1.5～2.5 秒** 后消失；100% 可略长，注意别和结算大动画硬叠太狠。  
3. **同档不重复**：本周目已播过的档不再播；「重置进度」后档位从零再来。  
4. **短库**：题很少时一斩可能跨多档——只播**最高跨过档**，或题数过少时弱化文案、只留闪电。  
5. **层级**：字短暂浮在条上/条内；勿盖住题干。

---

## 闪电特效（四档充能）

与文案同档，像充能：

| 档 | 特效强度（方向） |
|----|------------------|
| 25% | 填充前沿一点小闪 / 轻跳 |
| 50% | 填充段短促电流感 |
| 75% | 更密一点，仍克制 |
| 100% | 整条过电一次，然后收住（可接结算） |

用现有斩题强调色，避免堆默认「霓虹紫光」风。
