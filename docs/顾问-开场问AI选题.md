# 顾问备忘：大学女生常问 AI 什么 · 开场选题

> 供作者写新开场手稿时对照。不改现网剧本。  
> 日期：2026-09-20  
> 约束回扣：开场 = 用户顶替她手机里的 AI；手写；由「AI 错解」联想到世界不同；日子跟玩家真实日期对齐；结束后落「认识但不熟悉」。

---

## 1. 现实里大学生（含女生）常扔给 AI 的几类

不是「女生专属清单」，而是校园场景里**出现频率高、且女生并不更少**的用法。按「像不像会砸进对话框」排序：

| 类 | 典型问法 | 真实动机 | 紧急感 |
|----|----------|----------|--------|
| **A. 直接砸题 / 要答案** | 原题粘贴；「选哪个」「简答怎么写」 | 赶作业、赶考、懒得想 | 极高 |
| **B. 代码报错** | 贴报错 + 代码；「为啥编译不过」 | 大一编程课极常见 | 高 |
| **C. 作文 / 公文润色** | 思修、形势政策、英语作文、请假条、申请书 | 交差、怕写丑 | 中高 |
| **D. 翻译 / 摘要** | 英文文献、PPT、长通知「总结一下」 | 省时间 | 中 |
| **E. 生活怎么做** | 军训带什么、洗衣、选课、宿舍规矩、白鞋怎么洗 | 第一次独立生活 | 中（季节强） |
| **F. 社交话术** | 「室友这样回我怎么接」「怎么拒人」 | 怕尴尬 | 中 |
| **G. 轻决策 / 情绪倾诉** | 「我该不该…」「好累啊你陪我聊聊」 | 要个听众 | 低～中 |
| **H. 兴趣工具** | 游戏攻略、歌单、穿搭、食谱 | 闲下来才问 | 低 |

女生侧相对更常出现的是 **C、E、F**；理工课里 **A、B** 男女都猛。Lykie 是人工智能专业大一 → **A/B 完全成立**，不必为了「像女生」避开题和代码。

她那边「AI = 人工接线」：她心里预期更像 **查题客服 / 模板回复**，不是树洞、不是朋友。开场第一句若太像对闺蜜倾诉，会和世界观打架。

## 2. 开场选题的硬过滤器（比「真不真实」更重要）

一条问题适不适合当开场，看能否同时满足：

1. **值得砸进对话框**（有一点急或有一点卡住），否则不像「打开 AI」。
2. **「错解」能自然发生**：你按「人 / 另一个世界」回，她会觉得这不像她世界里的人工 AI。
3. **能拐到「世界不同」**：错解最好碰在**两边日子/常识会岔开**的点上，而不是纯讲题讲错。
4. **不锁死期末**：日期对齐玩家屏幕 → 不宜写死「明天交卷/期末周」（旧稿问题）。
5. **不提前开私密**：怕水、病、家庭、宿舍志 → 开场不要。
6. **不让作者去编自己不会的女生日常**：假日常已不是核；生活题要薄、可含糊。

## 3. 按 Lykie 档案筛选：推荐 / 可用 / 慎用

### 优先推荐（写开场）

| 候选 | 为什么贴她 | 「错解 → 世界不同」怎么接 | 注意 |
|------|------------|---------------------------|------|
| **B′. C 语言卡住（报错或作业点）** | 专业、课表、学习通写 C、床上桌锚都在 | 你回得像真人（追问环境/让她贴完整代码/说「我这边工具不一样」）→ 她觉得人工 AI 不该这样 → 世界岔开 | 别写成期末生死局；可以是「今晚要交学习通」级小急 |
| **A′. 一道不长的课内题（高数/计导/英语皆可）** | 大学生最高频；她「直接砸」有辨识度 | 你没给标准答案、反而问她进度/聊开 → 错位 | 容易像旧砸题稿；若用，**弱化作弊生死感**，强化错位感 |
| **E′. 极薄的「怎么坐得住 / 晚上怎么过」** | 缺日常、会向人借；QQ 音乐听歌写作业 | 你按「你那边大学生」答，她发现细节对不上（没有的 App、不同的宿舍节奏）→ 世界不同 | 紧急感弱，要靠短句连发或「明天有课好烦」带一点毛躁，不要写成树洞 |

### 可用（第二梯队）

- **薅会员 / QQ 音乐怎么弄** — 很她，但戏剧弱；适合当开场里的第二问，不适合当第一砸。
- **泰拉瑞亚卡关** — 志趣好，紧急感不足；更适合开场后半「新鲜感多问」或近挖点。
- **思修/英语作文润色** — 现实感强；错解可走「你那边课程名/作业形态不一样」。略工具感，人设锋芒不如 C/薄日常。

### 慎用 / 不建议当第一问

- **室友矛盾、恋爱话术、深度情绪树洞** — 她对陌生人冷；也逼作者写宿舍志。
- **病、手术、怕水** — 阶段太高；开场禁止。
- **「你是不是真的 AI / 有没有意识」** — 把核话题提前审完，后面没戏。
- **锁死期末交卷倒计时** — 与「日期跟玩家对齐」抢优先级。

## 4. 顾问拍板建议（只选一个主问题）

**主推荐：学习通上的 C 作业卡点（B′）。**

理由（专业 + 产品 + 人设叠在一起）：

1. 大一女生（含理工）问 AI「这段 C 为啥不行 / 指针怎么理解」极其常见，不违和。  
2. 咬死档案：人工智能专业、C 程序设计、学习通、床上桌晚上写作业。  
3. 不必期末：任何有课的学期夜晚都能成立；前几周军训也可改成「预习/整理」变体。  
4. 「人工 AI」预期是给步骤或改代码；你若像人一样问、扯远、或暴露你那边工具/常识 → **错解自然**。  
5. 学习站产品感在，但戏核是「接到一个不该在线的人」，不是再演一遍作弊惊险片。

**备选主问题：一道短的课内题（A′）**——若你更想保留「原题直砸」的辨识度；务必改掉旧稿的交卷生死节奏，把节拍重心放到错解与世界不同。

**不要用「纯生活树洞」当唯一第一句**——可以当她砸完正题之后、新鲜感里冒出来的第二句（更像她）。

---

## 5. 开场问题的「形状」建议（方便你开写）

无论选 B′ 还是 A′，第一波消息建议长这样（气质，不是定稿文案）：

1. **短、脏、急**：像复制粘贴，不修辞。  
2. **带着一点她的脾气**：不会时可以急，但不嘴硬到编造。  
3. **给「错解」留接口**：问题里最好有一个**两边世界容易岔开**的词（软件名、校园流程、习以为常的常识），而不只是纯知识点对错。  
4. **正题解决或搁置后**，再用新鲜感多问 → 铺到世界不同；不要第一句就宇宙课。

示例方向（非定稿）：

- C：贴一小段 +「学习通这份为啥过不了 / 报错看不懂」  
- 或：高数/计导一小题 +「这个到底怎么理解」  
- 错解触发词示例：你提到她那边没有的工具、或她以为 AI 不该有的态度（追问她是谁、让她自己想一步）

## 6. 一句话

大学女生问 AI，高频是**交差**（题、代码、作文）和**第一次独立生活的薄问题**；开场请选前者里最贴她课表的那条——**C 作业卡住**——用「回复不像人工客服」把戏拐到世界不同，而不是再写一场期末作弊。
