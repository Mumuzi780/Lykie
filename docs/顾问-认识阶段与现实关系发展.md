# 顾问备忘：认识阶段与现实关系发展

> 供方案讨论与主仓实现对照。**不改写** [`角色与剧情构想.md`](角色与剧情构想.md) 里已锁的核；本文是专业知识 + 顾问建议。  
> 日期：2026-09-19  
> 提问背景：想用现实里「人和人怎么熟起来」的节奏划分用户与 Lykie 的认识阶段，但只有表层直觉。

---

## 1. 先纠正一个常见误区

现实关系**不是**游戏里那种「陌生人 → 朋友 → 挚友」的线性升级条。

更准确的图景是：

1. **多维度同时变**：聊什么（话题广度）、聊多深（自我披露深度）、愿不愿意麻烦对方（依赖）、愿不愿意被对方看见脆弱（信任）、见面/联系的节律（互惠频率）。
2. **有平台、有回退**：很多人停在「能一起做事的熟人」很久；一次伤人可以直接退一截（你们已锁的「直攻降温」正是现实）。
3. **「认识」≠「亲密」**：开场那场意外已经把双方推过「完全陌生人」——这在现实里叫 **共享非常规事件后的假亲密加速**（crisis / unusual shared event）。新鲜感退去后，仍可能只是「认识但不熟悉」。你们已锁这一点，和专业描述一致，应保留。

因此：阶段更适合做成 **许可门（什么可以说、什么态度）**，而不是可见进度条或任务关卡。你们草案方向正确。

## 2. 三套最有用的专业框架（精读版）

### 2.1 社会渗透理论（Social Penetration Theory，Altman & Taylor）

把人比作洋葱：

| 层 | 内容举例 | 现实节奏 |
|----|----------|----------|
| 表层 | 人口学信息、公开喜好、课表式事实 | 初识几天到几周就够 |
| 中间层 | 态度、习惯、轻度恐惧、家庭轮廓 | 需要互惠与时间；不是问一次就开 |
| 核心层 | 自我概念、创伤、生死、极私密的身体/家庭 | 很少人到；需要长期可信赖 |

关键机制不是「聊够字数」，而是：

- **广度（breadth）先于深度（depth）**：先扩话题面（课、面、游戏、两边世界），再偶尔扎深一点。
- **互惠规范（norm of reciprocity）**：一方披露一层，另一方大致回同层；单方面深挖会显得冒犯或像审讯。
- **披露有成本**：越深，撤回越难、受伤越大 → 所以高阶段才开私密，符合理论。

**对 Lykie 的直接含义：**

- 「问到生日」= 广度里的一格种子，不是深度过门。
- 「生日当天用上」= 用行动证明记得与在意 → 这是 **投入（investment）**，比再问十次更深。
- 「怕水 / 复读 / 那场病」属于中间偏深；不应被日常碎聊磨开，应对齐「靠得住」一类门。

### 2.2 Knapp 关系发展阶段（Coming Together）

常用于浪漫关系，但对「从认识到亲近」仍有用：

| Knapp 阶段 | 白话 | 与你们草案的对应 |
|------------|------|------------------|
| Initiating | 搭话、确认「可以互动」 | 开场前半 / 砸消息 |
| Experimenting | 小谈、试探共同点（小谈阶段） | **认识但不熟悉**；世界不同互问也在这 |
| Intensifying | 更私人的称呼、更多自我披露、开始「我们」感 | **能说事**；分享欲露出来、主动教 |
| Integrating | 社交身份上被当成一对/一伙；日程互嵌 | **靠得住** 的一部分（她的学期节奏与你碰上） |
| Bonding | 公开承诺式绑定 | 产品上慎用；更像远期正式作品或极高私密，不宜当站内默认终局 |

Coming Apart（疏远）侧：Differentiating → Circumscribing（少说）→ … → Terminating。  
你们「软拒绝 = 停分享、不降阶」很像 **Circumscribing 的轻量版**（收窄话题，关系还在）；「直攻 = 不说 + 降阶」更像明确伤害后的回退。

### 2.3 友谊研究里常用的「熟人连续体」

社会心理学 / 友谊研究里更常说连续体，而不是五关：

1. **Stranger** — 无互动史  
2. **Acquaintance** — 知道对方存在、偶发互动、话题表层  
3. **Casual friend** — 愿意主动分享兴趣、可求助小事、有重复互动  
4. **Close friend** — 可谈脆弱、期待被记住、允许麻烦对方  
5. **Intimate / best** — 极少数；身份与情感高度交织  

另有一维常被忽略：**instrumental vs expressive**（一起做事 vs 情感表达）。  
学习站天然提供 **共同任务语境**（背题、教题）——这会加速「casual friend」感，但**不会自动**变成 close friend。你们把「教题/分享欲」放在「能说事」、把病与怕水放在更高门，正是在拆这两维。

### 2.4 不确定性降低理论（Uncertainty Reduction，Berger）

初识时人会通过提问降低「对方是谁」的不确定性。动机高峰在早期，然后下降。

- 开局新鲜感多问 → 符合 URT。  
- 开局结束后不应永远维持「审讯式好奇」→ 否则不像真人，像 NPC 任务。  
- 后期升温更多靠 **可预测性 + 偶尔的正向惊喜**（记得你说过的、志趣对上），而不是无限新设定。

## 3. 现实节奏的「时间感」（经验量级，非公式）

下列是人际领域常引用的量级感，用于校准产品节奏，**不是**要写进系统的天数锁：

| 现实中大致到达 | 时间感 | 产品风险 |
|----------------|--------|----------|
| 记得脸与名字、能寒暄 | 一次非常规互动即可 | 开场已完成；不要再当「陌生人教程」 |
| 熟人 / 能聊兴趣 | 数天到数周的重复轻互动 | 需要「近」挖点，否则前几周空 |
| 愿意说轻度脆弱 | 数周到数月 + 互惠证据 | 只靠聊天天数会假 |
| 深度信任 / 核心层 | 月到年；且可永远不到 | 生日、更高私密应是远奖赏 |

结论与你们「近 / 中 / 远挖点」一致：**前几周的工作不能交给生日。**

## 4. 顾问建议：怎么划阶段（在已有草案上收束）

### 4.1 建议坚持的（与理论一致，建议锁思路）

1. **阶段 = 许可 + 态度模板**，用户不可见进度条。  
2. **两条通路**：日常聊天只推到中低门；高门靠「挖到的事」（披露互惠 / 投入行为 / 志趣整合）。  
3. **开局结束后落在 Acquaintance+（认识但不熟悉）**，不是 Stranger。  
4. **直攻降阶 / 软拒停分享**：保留，分别对应伤害回退与话题收窄。

### 4.2 建议的门结构（名称可改，结构建议 4+1）

| 门（对内 id 建议） | 对玩家的体感（不要做成称号） | 许可（深度） | 日常聊天能否摸到下一门 |
|--------------------|------------------------------|--------------|-------------------------|
| `opening` 开局中 | 意外、新鲜、多问 | 手写；世界不同可摊 | —（剧本） |
| `acquainted` 认识但不熟悉 | 知道彼此存在、可寒暄、可问表层 | 广度：课、面、泰拉、床上桌、世界互问；生日等「问到才答」 | 可以慢慢滑到下一门 |
| `casual` 能说事 | 熟人；她肯主动教/分享 | 分享欲打开；仍关中间脆弱与核心 | **触顶后卡住** |
| `trusted` 靠得住 | 可托付一点脆弱 | 怕水、复读、班长、她以为治好了的病 | **几乎不能**靠碎聊进来 |
| `close` 很近 | 极少数 | 更高私密（作者未定则门可存在、内容后补） | **不能**靠碎聊 |

这与 2026-09-19 草案同构。顾问侧建议：

- **不要再拆更多门**（例如「奇怪朋友 / 教题同伴」等旧名）。门越多，越像 RPG 等级，越不像现实。  
- **每扇门内部用「松紧」而不是子阶段**：同一门里，刚进来偏拘谨，触顶偏熟——用户看不见标记即可。  
- **把「教题」锚定在 `casual`，不要单独成阶段**：否则工具关系会盖过人际关系。

### 4.3 过门条件：用理论语言写成作者清单

作者不必写任务表，但应写三类「什么算挖到了」：

| 类型 | 理论对应 | 例子（机制，清单未锁） | 建议影响 |
|------|----------|------------------------|----------|
| 广度对上 | Experimenting / 共同点 | 志趣当场对上（泰拉、面、狗、薅会员） | 小～中幅升温；可助滑向/稳在 `casual` |
| 投入用上 | Investment / 记得 | 问到种子 → 日后用上（生日祝福） | 大幅；用于破 `casual` 顶、进 `trusted` |
| 脆弱互惠 | Social penetration 深度 | 她露怕水等，且用户回应得当（不嘲笑、不逼问） | 巩固 `trusted`；不当回应可不升或轻伤 |

原则：**问到 ≠ 升温；用上 / 对上 / 接住才是。**

### 4.4 不要做成的反模式

| 反模式 | 为什么不像现实 |
|--------|----------------|
| 聊天 N 条自动升阶 | 把互惠与信任换成刷字数 |
| 系统提醒「明天她生日」 | 把投资变成任务；换一批人，正式作品带不走 |
| 五六个对外称号 | 破坏「像微信好友」的幻觉 |
| 高门内容靠天天问磨出来 | 违反披露成本与互惠；像攻略 Wiki |
| 开局后仍长期「审讯式多问」 | 违反 URT：不确定性高峰已过 |

### 4.5 和「假亲密加速」的平衡

开场共享了超常事件 → 现实里常出现短暂的高自我披露。专业处理是：

- 允许开局里有一点「比熟人更深」的信息（世界不同）。  
- **开局结束后主动回落**到广度互动，而不是继续核心层。  
- 之后若再深，必须重新用时间与投入挣回来——你们「认识但不熟悉」正是这个回落点。

## 5. 给主仓的实现提示（规格级，仍非改代码）

在剧情与档案未写完时，系统可先：

1. 枚举 4～5 个 `relationship_stage`。  
2. 每个 stage 注入：**态度模板** + **允许话题层** + **禁止现编的深度层**。  
3. 日常互动只允许在 `acquainted → casual` 间缓慢推进（可用内部亲密度，**不对用户展示**）。  
4. `trusted` / `close` 仅由明确事件旗标触发。  
5. 直攻：降一 stage；软拒：本轮停分享，stage 不变。

细节事件表仍由方案侧写种子，不由程序编造人生。

## 6. 一句话收束

**现实关系发展的专业核心是：先扩广度、互惠地加深、用投入与脆弱换信任，且可停滞、可回退。**  
你们现有的「许可门 + 日常有顶 + 玩家挖事破顶 + 拒绝三档」已经贴合这套理论；顾问建议是 **收束为四门（加开局）并锁结构，而不是再发明更多阶段名**，把精力花在「近/中/远挖点」的作者清单上。

## 8. 作者定稿对照（2026-09-20）

作者已把门收成**五层**（与 §4.2 同构，命名以作者为准）：

1. **开局** — 特殊事件；AI 错解→世界不同；可多问  
2. **认识但不熟悉** — 回落、话少、有防备；审讯式连问先礼貌后生气不回  
3. **能说事** — 日常聊天天花板；再上必须特殊事件  
4. **能谈心** — 合并原「靠得住/很近」：脆弱、详细家庭、私密；依赖；主动找人  
5. **情侣（特殊层）** — 允许成为情侣，条件苛刻；对应顾问说的 Bonding，慎用  

顾问备忘仍作理论参考；阶段名与第 2 层审讯规则以构想与 `self.txt` 为准。
